# Lane 15: AI agents and assistants

Question: which AI assistants, browser agents and MCP routes can do one-person reseller work (draft listings from photos, fill listing forms, research comps, write buyer replies), and which do Etsy, eBay, Shopify, Facebook and Chairish terms allow? Date 2026-11-07. V = vendor page read; U = the fetchers could not read it.

## Bottom line

- The browser agent is already paid for. Claude in Chrome is "Available on all paid plans". Claude Cowork "Works with a paid plan"; its built-in browser can "open sites, read pages, click, type, and fill forms" on Windows, macOS and Linux (beta). Caution: browser sessions and Claude Code draw from "the same pool". (V)
- Terms decide where it may run. eBay bans "LLM-driven bots" and "buy-for-me agents" without "the prior express permission of eBay". Meta bans automated access even "while logged-in". Chairish bans processes that run "while you are not logged into the Services" and any scraping. Anthropic's Usage Policy makes the user responsible for agent actions. So: browser agent on Etsy only, Ricky watching, never scheduled; eBay through the API. (V)
- The API routes are free and wait on Step 0 keys. eBay's official MCP server (eBay/npm-public-api-mcp, Apache-2.0, pushed 2026-10-27) is read-only ("Only GET requests are supported"), the terms-safe comps route. Writes need YosefHayim/ebay-mcp (MIT, 194 stars, 379 tools; latest commit Oct 29, 2026, not 2026-11-06). Etsy's Seller App is "Automated, near-instant for eligible sellers", "Your shop only", "Commercial use Not permitted"; no fee is stated. aserper/etsy-mcp is dormant: all 21 commits landed Apr 2, 2026, not 2026-11-07. (V)
- Shopify Sidekick is "BUILT INTO EVERY STORE" above Basic at "$39 USD/mo" monthly or "$29 USD/mo" yearly. Photo cleanup, product copy, workflow automation and review-before-apply are confirmed. Voice mode, order editing and Flow rest on a help page that returned 403, so they are U. The Shopify AI Toolkit plugin states no price; free is inferred. (V, part U)
- Dictation is free on both devices. Windows voice typing (Win+H) needs an internet connection; iPhone Dictation needs none, which matters in a thrift store with poor signal. Wispr Flow Free is "$0/mo" with "Limited words per week"; Pro is "$12/user/mo". The lane's "annual 20% discount" did not render (U). (V)
- OpenAI's consumer agents are gone ("ChatGPT agent is no longer available"; Atlas "has been retired"). The cloud browser lives in ChatGPT Work on paid plans "excluding Free and Go". Plus is "$20/month (billed monthly)", correcting the lane's "unknown"; Go stays U. Gemini Free is "$0/ month"; auto browse is in Google AI Pro at "$19.99/ month" as a US preview. (V)
- Best gaps finds: 3Dsellers hosted MCP (eBay, Etsy and Shopify writes, "no eBay developer account", Essential "$19" monthly or "$16 /Mo Billed Annually", 100 Listings, 7-day trial) as a fallback if Crosslist Gold disappoints; Apple Visual Intelligence as a free first-pass ID on a compatible iPhone; Zapier Free ("100 tasks per month") for Shopify order alerts, though "Etsy has not yet built an integration on Zapier." (V)

## Picks

Use now (free):
- Claude in Chrome or Cowork's built-in browser, Etsy only, "safety check on each action" on, Ricky watching. Jobs: read a finished Etsy draft back, pull sold comps from open tabs, draft buyer replies for Ricky to send.
- Windows voice typing and iPhone Dictation for the one-line item note the Haiku flow turns into a listing.
- Gemini Free and ChatGPT Free as second opinions on a maker's mark.
- Shopify Sidekick the day the store exists; the Shopify connector and the AI Toolkit plugin for the build.
- Wispr Flow Free for a week on both devices.
- After Step 0 keys: eBay's official MCP (comps), YosefHayim/ebay-mcp (eBay writes), aserper/etsy-mcp (Etsy writes; read the code first), the eBay half of Secondhand MCP.
- Apple Visual Intelligence if the iPhone qualifies; eBay Seller Hub Photo upload once the eBay account exists; Zapier Free later for Shopify order alerts.

Pay when it earns it:
- Wispr Flow Pro, "$12/user/mo": when the weekly word cap stops a listing session.
- 3Dsellers Essential, "$19" monthly or "$16 /Mo Billed Annually": only if the Crosslist Gold trial disappoints, and after confirming Etsy and Shopify publishing on that tier.
- Google AI Pro, "$19.99/ month": only if Ricky leaves Claude; auto browse is still a US preview.

Skip:
- ChatGPT paid plans and the cloud browser: agent and Atlas retired, the cloud browser runs unattended, Claude covers the same jobs.
- Perplexity Comet (price unreadable), Opera Neon ("$19.90/month", nothing reseller-specific), Copilot paid tiers (the free Edge pane is enough).
- Superwhisper and Aqua Voice (Wispr Flow Free covers it); Nanobrowser (a stand-in only if the paid plan goes).
- Listing Writer, seerxo, n8n and OpenClaw as running systems: each is a second stack beside the Supabase dashboard. Borrow their ideas instead.
- Any browser agent, scheduled task or cookie-replay MCP on eBay, Facebook Marketplace or Chairish. Marketplace stays manual.

## Contradictions with earlier decisions

None that overturn a decision. Two overlaps:
- Crosslist Gold (trial): 3Dsellers Essential lists to eBay, Etsy and Shopify through APIs with "no eBay developer account" at "$19" monthly for 100 listings. The gaps file calls it "a fallback, not a new decision". The lane asserts Crosslist uses eBay's API, the route the User Agreement allows; that was not re-verified here.
- rembg BiRefNet: Sidekick will "Upgrade your phone photos to studio shots" and, per a 2026-10-24 note, "can now generate images with transparent backgrounds". It covers Shopify photos only, needs the store plan and lands inside Shopify, so rembg stays for Etsy and the site.
- Claude Haiku drafts: nothing argues against it. Listing Writer confirms the pattern (own Anthropic key, "pennies per item"). Caution: Claude browser sessions and Claude Code share "the same pool"; drafts through the API key are unaffected.
- Buffer Free, Canva Free, Instagram Edits, Supabase, Pushover, fixed Etsy shipping classes: nothing in these files touches them.
