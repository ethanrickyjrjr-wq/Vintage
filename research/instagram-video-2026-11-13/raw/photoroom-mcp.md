# Edit images in Claude with Photoroom
Add Photoroom as a custom connector, then ask Claude to remove backgrounds, stage products, put clothes on a model and more. Works in Claude, Cowork and Claude Code.
[Add connector in Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=Photoroom%20MCP&connectorUrl=https%3A%2F%2Fmcp.photoroom.com%2Fmcp)

## Add the Photoroom connector to Claude
Sign in with your Photoroom account and Photoroom creates the API key for you. Works on every Claude plan.
![Claude.ai connector settings with the Photoroom server address entered](https://storyblok-cdn.photoroom.com/f/191576/1152x768/f06ba04e64/mcp-setup-claude-ai.webp/m/3840x0/filters:quality\(80\):no_upscale\(\):format\(webp\))
Claude.ai
Go to ‘Customize’, then ‘Connectors’. Click ‘+ Add’, choose ‘Add custom connector’, and paste <https://mcp.photoroom.com/mcp>.
![Claude desktop app connector settings with the Photoroom server address entered](https://storyblok-cdn.photoroom.com/f/191576/1152x768/bbdf4c6e8f/mcp-setup-claude-cowork.webp/m/3840x0/filters:quality\(80\):no_upscale\(\):format\(webp\))
Claude Cowork
In the Claude desktop app, go to ‘Customize’, then ‘Connectors’. Click ‘+ Add’, choose ‘Add custom connector’, and paste <https://mcp.photoroom.com/mcp>.
![Terminal command that adds the Photoroom MCP server to Claude Code](https://storyblok-cdn.photoroom.com/f/191576/1152x768/a2dc0f5a09/mcp-setup-claude-code.webp/m/3840x0/filters:quality\(80\):no_upscale\(\):format\(webp\))
Claude Code
Run this in your terminal:  
`claude mcp add --transport http Photoroom https://mcp.photoroom.com/mcp`
For batch edits and scheduled runs, see [Photoroom in Claude Code](https://www.photoroom.com/mcp/claude-code).

## Frequently asked questions
#### Can Claude edit images?
Yes. With the Photoroom MCP connected, Claude can edit your images: remove the background from a photo, add shadows, relight, iron garments, or make flat lay and ghost mannequin shots, and much more, in Claude, Cowork and Claude Code.
#### How does Photoroom work with Claude?
Photoroom connects to Claude through MCP (Model Context Protocol), an open standard for giving AI tools access to external capabilities. Once connected, Claude can call Photoroom tools like background removal, image generation, virtual model, ghost mannequin, product placement, upscaling and more, directly within your conversation.
#### What's the difference between Claude, Claude Cowork & Claude Code?
  * **Claude** is the chat app on the web, desktop and mobile.
  * **Cowork** runs in the Claude desktop app and works through files and multi-step tasks for you.
  * **Claude Code** runs in your terminal and is built for developers.
  * Photoroom works with all three.


#### What tools does Photoroom give Claude?
The Photoroom MCP gives Claude access to our entire tool library through one endpoint. Every Photoroom API tool is included, so anything the API can do, Claude can do, from [ironing](https://www.photoroom.com/api/ironing) and relighting to flat lay and ghost mannequin. Tools stay up to date and Claude picks the best one for the edit you ask for.
#### How does pricing work?
Photoroom tools in Claude use your Photoroom API credits at the same rates as the API, with no extra fee for using them through Claude. See [API pricing](https://www.photoroom.com/api/pricing).
#### Do I need a separate API key?
No. The MCP server handles credentials automatically by creating a new ClaudeMCP API key in existing API spaces, or by creating a new API space with a Claude-specific key.
#### How do I edit images in Claude?
Connect the Photoroom MCP to Claude, then upload an image, add a folder or provide a URL of images and describe the edit you want in plain English: "remove the background," "place this on a marble surface with a soft shadow," "put this jacket on a model." Claude calls Photoroom's image-editing API and returns the finished image in the chat. No design tools or parameters to learn; you just describe the result you're after.
#### What's the best MCP for e‑commerce product photos?
Photoroom is purpose-built for commerce imagery. Where general image tools generate pictures, Photoroom edits your actual product, keeping the item exactly as it is while fixing the background, lighting and shadows. It covers the jobs e‑commerce teams do daily: background removal, AI shadows, lifestyle backgrounds, ghost mannequin, placing apparel on virtual models and much more. The models are trained on commerce use cases, so results are listing-ready rather than approximate. It also works outside Claude: [see every app it works with](https://www.photoroom.com/mcp).
#### Can I batch edit through Claude?
In a chat, attach a few images or share links. For bigger batches, use Cowork or Claude Code and point Claude at a folder or a list of URLs. It can work through large batches, including on a schedule. [See how in Claude Code](https://www.photoroom.com/mcp/claude-code).
#### How do I revoke the MCP API key?
You can delete an API key at any time from the API Dashboard in your Photoroom subscription. You can also disconnect the Photoroom MCP which removes authorization to Claude. When you re-authorize the MCP, it will generate a new API key for Claude to use.
#### What file formats and sizes are supported?
The API accepts PNG, JPEG, and WebP for both input and output (PNG is the default output, and the only format that preserves transparency alongside WebP - JPEG does not). Maximum file size is 30MB and maximum resolution is 5,000px on the longest side; larger images are accepted under 30MB but resized down to 5,000px. For best performance, keep images at or below 25 megapixels. Larger files take longer to process, so increase your client timeout if you hit delays.
#### Do I need a paid Claude plan?
No. Custom connectors work on every Claude plan. [Free plans can add one custom connector](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
#### Should I use the MCP or call the API directly?
Use the MCP to edit images by chatting with Claude, Cowork or Claude Code, with no code needed. Use the API when you’re building edits into your own product or pipeline. Claude Code or Codex can write that integration for you from our [ready-made prompt](https://docs.photoroom.com/getting-started/integrating-with-claude-code-codex-or-cursor). Our [guide to choosing between the MCP and the API](https://www.photoroom.com/mcp/mcp-vs-api) compares them side by side.
