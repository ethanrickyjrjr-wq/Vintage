## Frequently asked questions
#### Which API should I use?
The Photoroom API consists of two API endpoints, which are available in two different plans:
  * Use our Remove Background API if you only need to remove the background. (Basic API plan)
  * Use our Image Editing API to resize, replace backgrounds, adjust lighting, or add shadows (Plus API plan)


#### How can I get my API key?
In order to use the Photoroom API, you'll first need to activate the API for your account and obtain your unique API key. Here's how to do it:
  * **Activate the API for your account** : This can be done by [visiting your account settings](https://app.photoroom.com/api-dashboard) on the Photoroom website. Make sure that you're logged into your account.
  * **Copy your API key** : Once you've activated the API for your account, you'll be provided with a unique API key. This key is essentially your password to make API calls, so it's important to keep it safe and secure. You can retrieve your API key by following the [same link used for the activation](https://app.photoroom.com/api-dashboard).
  * **Use your API key** : The key must be passed in the `x-api-key` HTTP header on every request.
  * You can find more information in our [API documentation](https://docs.photoroom.com/#how-can-i-get-my-api-key).


#### Can I switch easily from Remove.bg to Photoroom?
Yes. Photoroom’s Remove Background API accepts the same argument names as remove.bg and returns the same response format. To switch, change the endpoint URL to `https://sdk.photoroom.com/v1/segment` and use a Photoroom API key. The rest of your code stays the same.
remove.bg’s standalone service closes on 1 December 2026, and its background removal moves to Leonardo.ai. [See how to migrate from the remove.bg API](https://www.photoroom.com/api/photoroom-vs-removebg).
#### Which image formats, sizes, and resolutions are supported?
For the input and result images, the Image Editing API (Plus API plan) supports four formats: PNG, JPEG, WEBP and AVIF. We recommend limiting images to 25 megapixels for optimal performance. Maximum File Size: 30MB. Maximum Resolution: 5,000 pixels on the widest side. Images with a larger resolution are supported (if they stay below 30MB), but will be resized down to 5,000 pixels on the widest side.  
  
The Remove Background API (Basic API plan) supports four formats for the input image: PNG, JPEG, WEBP and HEIC. For the result image, it supports three formats: PNG, JPEG and WEBP. Maximum File Size: 50MB. Maximum Resolution: 6,000 pixels on the widest side.
#### How does the Photoroom API integrate with enterprise workflows (PIM/DAM, CMS, e‑commerce)?
Photoroom works with the tools you already use. When a new product photo comes in, it cleans the background, applies your brand look, and puts the finished image back where your team needs it, ready for your site, ads, or marketplaces. Result: less manual editing, faster launches, and a more consistent catalog.
#### How do I integrate the API into my project?
The Photoroom API uses standard HTTP calls, so it works with any programming language or framework. Get your API key from the dashboard, then send your image to the edit endpoint. This example call gives a clean white background, a soft AI shadow, 9% padding and corrected lighting, and returns a WebP image:

```
curl --request POST \
  --url https://image-api.photoroom.com/v2/edit \
  --header 'x-api-key: YOUR_API_KEY' \
  --header 'pr-ai-shadows-model-version: 2026-04-15' \
  --form imageFile=@/path/to/product.jpg \
  --form background.color=white \
  --form shadow.mode=ai.preset-soft \
  --form padding=0.09 \
  --form lighting.mode=ai.preserve-hue-and-saturation \
  --form export.format=webp \
  --output result.webp
```

See the [quickstart guide](https://docs.photoroom.com/image-editing-api-plus-plan/quickstart-guide) for every setting.
#### How are API calls billed?
API usage is billed by the amount of images processed. Images are bought through a monthly subscription and consumed on each successful API call. Pricing details are [available here](https://www.photoroom.com/api/pricing). Need more than Ultra covers, or features like Visual Agents? [Talk to sales](https://www.photoroom.com/contact-sales). Note that 1 call to the [Image Editing API](https://docs.photoroom.com/image-editing-api-plus-plan/quickstart-guide) is worth 5 calls to the [Remove Background API](https://docs.photoroom.com/remove-background-api-basic-plan/quickstart-guide). This means that:
  * if you are on the Basic API plan, a call to the [Image Editing API](https://docs.photoroom.com/image-editing-api-plus-plan/quickstart-guide) will consume 5 images
  * if you are on the Plus API plan, a call to the [Remove Background API](https://docs.photoroom.com/remove-background-api-basic-plan/quickstart-guide) will consume 0.2 image

#### Is there an API to remove the background of my images?
Yes, our [Background Remover API](https://www.photoroom.com/api/remove-background) lets you automatically remove or replace image backgrounds at scale — perfect for integrating clean, ready-to-publish product photos into your workflow. You can upload images, process them in bulk, and get studio-quality results in seconds.
#### How does Flat Lay maintain consistency across large-scale catalogue shoots?
Photoroom's Flat Lay API processes every image through the same AI pipeline, ensuring uniform composition, spacing, and styling across your entire catalogue, no matter the volume. Teams can define their layout parameters once and apply them at scale via API, eliminating the manual variation that comes with traditional studio shoots. The result is a consistent, on-brand look across thousands of SKUs, delivered in a fraction of the time.
#### How is an image editing API used?
An image editing API, also called an image manipulation API, lets software edit images automatically: removing backgrounds, resizing, cropping, adding shadows or generating new scenes. Businesses integrate it into their product, PIM, DAM, or e‑commerce platform to process thousands or millions of images via API calls instead of editing them manually. Modern APIs like Photoroom's combine traditional processing with AI for advanced use cases: virtual models, ghost mannequin, flat lay generation, and automated QA.
