# Add fonts to your Brand Library (Web App)
How to add fonts to your Brand Library so that users can choose the same fonts consistently across the Space. Web App.
C
Written by Craig Wright
Updated this week

You can add fonts to your [Brand Library](https://help.photoroom.com/en/articles/10208814-what-is-a-brand-library) so everyone in the Space can use them. This helps you:
  * **Save time:** Pick fonts from a short list instead of the full font list.
  * **Stay on-brand:** Encourage your team to use only your brand fonts.
  * **Use your own fonts:** Upload custom and third-party fonts that are not in Photoroom.


**Note:** The Brand Library's **Fonts** section has a total count next to the heading. This shows the total number of font styles (regular, bold, italic, light, and so on), not font families. 
* * *
# Before you begin
Be aware that:
  * Custom and third-party fonts must be in one of these formats:
    * OTF (OpenType Font)
    * TTF (TrueType Font)
    * WOFF (Web Open Font Format)  
​
  * Only upload fonts that are open source or that you have a license to use.


* * *
# Steps (Web App)
To add fonts to a brand kit on the Web App:
  1. Log in to Photoroom at [app.photoroom.com](https://app.photoroom.com). 
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in. 
  3. Select **Brand Library**.
  4. In the **Fonts** section of the side panel, select **Add +**.
  5. Do one of the following:  
​
     * **Search** for the fonts you want to add to your Brand Library. 
     * Choose the fonts to add from the **list of fonts included in Photoroom**. 
     * Select **Upload your font** and then browse to the font files to upload. You will need to upload each version of the font separately (bold, italic, light, and so on).
  6. Use the switches to select the versions of the font to add to the Brand Library (**Regular** , **Italic** , **Bold** , and so on).  
​  
​**Important:** Photoroom only adds fonts for the versions that have the switch on. If all switches are off, no fonts are added.   
​
  7. If you upload a font, confirm you have the license for the font.
  8. Close the font selection dialog.


The fonts are now added to your Brand Library. When editing text in Photoroom, the Brand Library fonts will appear in the text layer's settings, in either the:
  * **Brand Library** section
  * **Style** section


For example, in the image below, the BEBAS NEUE regular font has been added to the Brand Library. It appears in the **Style** list in the text layer settings.

# Troubleshooting
## Fonts not added to Brand Library
If the fonts are not added to the Font Library, check that:
  * The font files are in one of the supported formats 
  * You enable the version switches for the font when you add it. If all the switches are off, Photoroom won't add the font.


## Fonts total doesn't match the number of chosen fonts
The **Fonts** heading in the Brand Library has a number next to it that shows the total number of styles added to the Brand Library. If this number does not match the number of chosen fonts:
  1. Select **Add**.
  2. Look in the Brand Library section. 
  3. If there are fonts that should not be included, select them and then select **Remove**.   
When the Brand Library section only shows the fonts that you expect to be there, the Fonts heading total should be correct.


The Fonts heading total can sometimes get out of sync if you add fonts to the Brand Library and then delete them.
