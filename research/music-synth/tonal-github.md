# tonal
[](https://github.com/tonaljs/tonal#tonal)
[![npm version](https://camo.githubusercontent.com/0837df7369a50d9e4392112e4ba811525a3adb774f8435e2b35785b2ef7f2ae7/68747470733a2f2f696d672e736869656c64732e696f2f6e706d2f762f746f6e616c2e7376673f7374796c653d666c61742d737175617265)](https://www.npmjs.com/package/tonal)
`tonal` is a music theory library. Contains functions to manipulate tonal elements of music (note, intervals, chords, scales, modes, keys). It deals with abstractions (not actual music or sound).
`tonal` is implemented in Typescript and published as a collection of Javascript npm packages.
It uses a functional programming style: all functions are pure, there is no data mutation, and entities are represented by data structures instead of objects.
## Example
[](https://github.com/tonaljs/tonal#example)

```
import { Chord, Interval, Note, Scale } from "tonal";

Note.midi("C4"); // => 60
Note.freq("a4"); // => 440
Note.accidentals("c#2"); // => '#'
Note.transpose("C4", "5P"); // => "G4"
Interval.semitones("5P"); // => 7
Interval.distance("C4", "G4"); // => "5P"

// Scales
Scale.get("C major").notes; // => ["C", "D", "E", "F", "G", "A", "B"];
[1, 3, 5, 7].map(Scale.degrees("C major")); // => ["C", "E", "G", "B"]

Chord.get("Cmaj7").name; // => "C major seventh"

// Chord inversions
const triad = Chord.degrees("Cm");
[1, 2, 3].map(triad); // => ["C", "Eb", "G"];
[2, 3, 1].map(triad); // => ["Eb", "G", "C"];
[3, 1, 2].map(triad); // => ["G", "C", "Eb"];
```

## Install
[](https://github.com/tonaljs/tonal#install)
Install all packages at once:

```
npm install --save tonal
```

You can read [CHANGELOG here](https://github.com/tonaljs/tonal/blob/main/docs/CHANGELOG.md).
## Usage
[](https://github.com/tonaljs/tonal#usage)
Tonal is compatible with both ES5 and ES6 modules, and browser.
#### ES6 `import`:
[](https://github.com/tonaljs/tonal#es6-import)

```
import { Note, Scale } from "tonal";
```

#### ES5 `require`:
[](https://github.com/tonaljs/tonal#es5-require)

```
const { Note, Scale } = require("tonal");
```

#### Browser
[](https://github.com/tonaljs/tonal#browser)
You can use the browser version from jsdelivr CDN directly in your html:

```
<script src="https://cdn.jsdelivr.net/npm/tonal/browser/tonal.min.js"></script>
<script>
  console.log(Tonal.Key.minorKey("Ab"));
</script>
```

Or if you prefer, grab the [minified browser ready version](https://raw.githubusercontent.com/tonaljs/tonal/master/packages/tonal/browser/tonal.min.js) from the repository.
#### Bundle size
[](https://github.com/tonaljs/tonal#bundle-size)
`tonal` includes all published modules.
Although the final bundle it is small, you can reduce bundle sizes even more by installing the modules individually, and importing only the functions you need.
Note that individual modules are prefixed with `@tonaljs/`. For example:

```
npm i @tonaljs/note
```


```
import { transpose } from "@tonaljs/note";
transpose("A4", "P5");
```

## Documentation
[](https://github.com/tonaljs/tonal#documentation)
Visit the [documentation site](https://tonaljs.github.io/tonal/docs) or the README.md of each module 👇
#### Notes and intervals
[](https://github.com/tonaljs/tonal#notes-and-intervals)
  * [@tonaljs/note](https://github.com/tonaljs/tonal/blob/main/packages/note): Note operations (simplify, transposeBy )
  * [@tonaljs/midi](https://github.com/tonaljs/tonal/blob/main/packages/midi): Midi number conversions
  * [@tonaljs/interval](https://github.com/tonaljs/tonal/blob/main/packages/interval): Interval operations (add, simplify, invert)
  * [@tonaljs/abc-notation](https://github.com/tonaljs/tonal/blob/main/packages/abc-notation): Parse ABC notation notes


#### Scales and chords
[](https://github.com/tonaljs/tonal#scales-and-chords)
  * [@tonaljs/scale](https://github.com/tonaljs/tonal/blob/main/packages/scale): Scales
  * [@tonaljs/scale-type](https://github.com/tonaljs/tonal/blob/main/packages/scale-type): A dictionary of scales
  * [@tonaljs/chord](https://github.com/tonaljs/tonal/blob/main/packages/chord): Chords
  * [@tonaljs/chord-type](https://github.com/tonaljs/tonal/blob/main/packages/chord-type): A dictionary of chords
  * [@tonaljs/chord-detect](https://github.com/tonaljs/tonal/blob/main/packages/chord-detect): Detect chords from notes
  * [@tonaljs/pcset](https://github.com/tonaljs/tonal/blob/main/packages/pcset): Pitch class sets. Compare note groups.


#### Voicings
[](https://github.com/tonaljs/tonal#voicings)
  * [@tonaljs/voicing](https://github.com/tonaljs/tonal/blob/main/packages/voicing): Voicings and voice leadings for chords
  * [@tonaljs/voice-leading](https://github.com/tonaljs/tonal/blob/main/packages/voice-leading): Voice leading logic for transitions between voicings
  * [@tonaljs/voicing-dictionary](https://github.com/tonaljs/tonal/blob/main/packages/voicing-dictionary): Collections of chord voicings


#### Keys, chord progressions
[](https://github.com/tonaljs/tonal#keys-chord-progressions)
  * [@tonaljs/key](https://github.com/tonaljs/tonal/blob/main/packages/key): Major and minor keys, it's scales and chords
  * [@tonaljs/mode](https://github.com/tonaljs/tonal/blob/main/packages/mode): A dictionary of Greek modes (ionian, dorian...)
  * [@tonaljs/progression](https://github.com/tonaljs/tonal/blob/main/packages/progression): Chord progressions
  * [@tonaljs/roman-numeral](https://github.com/tonaljs/tonal/blob/main/packages/roman-numeral): Parse roman numeral symbols


#### Time, rhythm
[](https://github.com/tonaljs/tonal#time-rhythm)
  * [@tonaljs/rhythm-pattern](https://github.com/tonaljs/tonal/blob/main/packages/rhythm-pattern): Generate and manipulate rhythmic patterns
  * [@tonaljs/time-signature](https://github.com/tonaljs/tonal/blob/main/packages/time-signature): Parse time signatures
  * [@tonaljs/duration-value](https://github.com/tonaljs/tonal/blob/main/packages/duration-value): Note duration values


#### Utilities
[](https://github.com/tonaljs/tonal#utilities)
  * [@tonaljs/core](https://github.com/tonaljs/tonal/blob/main/packages/core): Core functions (note, interval, transpose and distance)
  * [@tonaljs/collection](https://github.com/tonaljs/tonal/blob/main/packages/collection): Utility functions to work with collections (range, shuffle, permutations)
  * [@tonaljs/range](https://github.com/tonaljs/tonal/blob/main/packages/range): Create note ranges


## Contributing
[](https://github.com/tonaljs/tonal#contributing)
Read [contributing document](https://github.com/tonaljs/tonal/blob/main/docs/CONTRIBUTING.md). To contribute open a PR and ensure:
  * If is a music theory change (like the name of a scale) link to reliable references.
  * If is a new feature, add documentation: changes to README of the affected module(s) are expected.
  * Ad tests: changes to the test.ts file of the affected module(s) are expected.
  * All tests are green
