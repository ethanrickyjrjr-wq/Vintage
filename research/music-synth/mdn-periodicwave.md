# PeriodicWave
Baseline 
Widely available
This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


The **`PeriodicWave`**interface defines a periodic waveform that can be used to shape the output of an[`OscillatorNode`](https://developer.mozilla.org/en-US/docs/Web/API/OscillatorNode).
`PeriodicWave` has no inputs or outputs; it is used to define custom oscillators when calling [`OscillatorNode.setPeriodicWave()`](https://developer.mozilla.org/en-US/docs/Web/API/OscillatorNode/setPeriodicWave). The `PeriodicWave` itself is created/returned by [`BaseAudioContext.createPeriodicWave`](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/createPeriodicWave).

##  [Constructor](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave#constructor) 

[`PeriodicWave()`](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave/PeriodicWave "PeriodicWave\(\)")
    
Creates a new `PeriodicWave` object instance using the default values for all properties. If you wish to establish custom property values at the outset, use the [`BaseAudioContext.createPeriodicWave`](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/createPeriodicWave) factory method instead.
##  [Instance properties](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave#instance_properties)
None; also, `PeriodicWave` doesn't inherit any properties.
##  [Instance methods](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave#instance_methods)
None; also, `PeriodicWave` doesn't inherit any methods.
##  [Example](https://developer.mozilla.org/en-US/docs/Web/API/PeriodicWave#example)
See [`BaseAudioContext.createPeriodicWave`](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/createPeriodicWave) for simple example code that shows how to create a `PeriodicWave` object containing a simple sine wave.
