# BaseAudioContext: decodeAudioData() method
Baseline 
Widely available
This feature is well established and works across many devices and browser versions. It’s been available across browsers since April 2021.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


The `decodeAudioData()` method of the [`BaseAudioContext`](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext) Interface is used to asynchronously decode audio file data contained in an [`ArrayBuffer`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer) that is loaded from [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch "fetch\(\)"), [`XMLHttpRequest`](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest), or [`FileReader`](https://developer.mozilla.org/en-US/docs/Web/API/FileReader). The decoded [`AudioBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) is resampled to the [`AudioContext`](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext)'s sampling rate, then passed to a callback or promise.
This is the preferred method of creating an audio source for Web Audio API from an audio track. This method only works on complete file data, not fragments of audio file data.
This function implements two alternative ways to asynchronously return the audio data or error messages: it returns a [`Promise`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) that fulfills with the audio data, and also accepts callback arguments to handle success or failure. The primary method of interfacing with this function is via its Promise return value, and the callback parameters are provided for legacy reasons.

##  [Syntax](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#syntax)
###  [Parameters](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#parameters) 

[`arrayBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#arraybuffer)
    
An ArrayBuffer containing the audio data to be decoded, usually grabbed from [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch "fetch\(\)"), [`XMLHttpRequest`](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest) or [`FileReader`](https://developer.mozilla.org/en-US/docs/Web/API/FileReader). 

[`successCallback` Optional](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#successcallback)
    
A callback function to be invoked when the decoding successfully finishes. The single argument to this callback is an [`AudioBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) representing the _decodedData_ (the decoded PCM audio data). Usually you'll want to put the decoded data into an [`AudioBufferSourceNode`](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode), from which it can be played and manipulated how you want. 

[`errorCallback` Optional](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#errorcallback)
    
An optional error callback, to be invoked if an error occurs when the audio data is being decoded.
###  [Return value](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#return_value)
A [`Promise`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) object that fulfills with the _decodedData_. If you are using the XHR syntax you will ignore this return value and use a callback function instead.
##  [Examples](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#examples)
In this section we will first cover the promise-based syntax and then the callback syntax.
###  [Promise-based syntax](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#promise-based_syntax)
In this example `loadAudio()` uses [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch "fetch\(\)") to retrieve an audio file and decodes it into an [`AudioBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer). It then caches the `audioBuffer` in the global `buffer` variable for later playback.
**Note:** You can [run the full example live](https://mdn.github.io/webaudio-examples/decode-audio-data/promise/ "External link \(opens in new tab\)"), or [view the source](https://github.com/mdn/webaudio-examples/tree/main/decode-audio-data/promise "External link \(opens in new tab\)").
###  [Callback syntax](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData#callback_syntax)
In this example `loadAudio()` uses [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch "fetch\(\)") to retrieve an audio file and decodes it into an [`AudioBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) using the callback-based version of `decodeAudioData()`. In the callback, it plays the decoded buffer.
**Note:** You can [run the full example live](https://mdn.github.io/webaudio-examples/decode-audio-data/callback/ "External link \(opens in new tab\)"), or [view the source](https://github.com/mdn/webaudio-examples/tree/main/decode-audio-data/callback "External link \(opens in new tab\)").
