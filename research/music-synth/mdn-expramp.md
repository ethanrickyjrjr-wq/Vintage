# AudioParam: exponentialRampToValueAtTime() method
Limited availability 
This feature is not Baseline because it does not work in some of the most widely-used browsers.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


The **`exponentialRampToValueAtTime()`**method of the[`AudioParam`](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam) Interface schedules a gradual exponential change in the value of the [`AudioParam`](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam). The change starts at the time specified for the _previous_ event, follows an exponential ramp to the new value given in the `value` parameter, and reaches the new value at the time given in the `endTime` parameter.
**Note:** Exponential ramps are considered more useful when changing frequencies or playback rates than linear ramps because of the way the human ear works.

##  [Syntax](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#syntax)
###  [Parameters](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#parameters) 

[`value`](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#value)
    
A floating point number representing the value the `AudioParam` will ramp to by the given time. 

[`endTime`](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#endtime)
    
A double representing the exact time (in seconds) after the ramping starts that the changing of the value will stop.
###  [Return value](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#return_value)
A reference to this `AudioParam` object. In some browsers older implementations of this interface return [`undefined`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/undefined).
##  [Examples](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/exponentialRampToValueAtTime#examples)
