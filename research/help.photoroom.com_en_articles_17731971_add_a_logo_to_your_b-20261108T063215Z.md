There are 3 ways to add a logo to a Brand Library on the Web App version of Photoroom:
  * Add a logo to a Brand Library
  * Save a logo on a design to a Brand Library
  * Import a logo from a website   
For details, see [Import website assets to a Brand Library (Web App)](https://help.photoroom.com/en/articles/17731485-import-website-assets-into-a-brand-library-web-app)


In this article, we explain how to add and save a logo to the Brand Library.
* * *
# Steps (Web App)
Follow the instructions in the sections below to add a logo file to a Brand Library or save a logo layer to a Brand Library.  
​
* * *
## Add a logo to a Brand Library
To manually add a logo to a Brand Library:
  1. Log in at [app.photoroom.com](https://app.photoroom.com).
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in.
  3. Select **Brand Library**.
  4. In the **Logos** section, select **Add**.
  5. Select the logo file you want to upload.  
Photoroom adds the logo to your Brand Library. It also creates a color palette based on the colors in the logo.


  
Everyone who uses the Space can now insert the same logo from the Brand Library.
**Note:** Alternatively, you can select **Create logo with AI** and use Photoroom's Logo tool to create a logo. For instructions, see [How to use the Logo tool](https://help.photoroom.com/en/articles/16442326-how-to-use-the-logo-tool).  
​
* * *
## Save a logo to a Brand Library
If your logo exists as a single, selectable layer on a design, batch image, or product image, you can save it to your Brand Library.
**Note:** It is only possible to save a single layer to the Brand Library, so if you want the entire logo (background and foreground), they must both be on the same layer. 
  1. Open the design, batch image, or product image that contains the logo as a single layer.
  2. Select the logo layer.
  3. Select **Save** in the layer settings for the logo.
  4. Select **Save as logo**.  
Photoroom saves the layer as a logo in the Space's Brand Library. It also creates a color palette based on the colors in the logo.


Everyone who uses the Space can now insert the same logo from the Brand Library. For details, see [Use Brand Library layers or logos in a design (Web App)](https://help.photoroom.com/en/articles/18225678-use-brand-library-layers-or-logos-in-a-design-web-app).
