# CanvasRenderingContext2D: filter property
Limited availability 
This feature is not Baseline because it does not work in some of the most widely-used browsers.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


The **`CanvasRenderingContext2D.filter`**property of the Canvas 2D API provides filter effects such as blurring and grayscaling. It is similar to the CSS[`filter`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/filter) property and accepts the same values.
## In this article
  * [Value](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#value)
  * [Examples](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#examples)
  * [Specifications](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#specifications)
  * [Browser compatibility](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#browser_compatibility)
  * [See also](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#see_also)


##  [Value](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#value)
The `filter` property accepts a value of `"none"` or one or more of the following filter functions in a string. 

[`url()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/url_function)
    
A CSS [`url()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/url_function). Takes any URL that resolves to SVG filter element. This can be the ID of an element, a path to external XML file, or even a data encoded SVG value. 

[`blur()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/blur)
    
A CSS [`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length). Applies a Gaussian blur to the drawing. It defines the value of the standard deviation to the Gaussian function, i.e., how many pixels on the screen blend into each other; thus, a larger value will create more blur. A value of `0` leaves the input unchanged. 

[`brightness()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/brightness)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Applies a linear multiplier to the drawing, making it appear brighter or darker. A value under `100%` darkens the image, while a value over `100%` brightens it. A value of `0%` will create an image that is completely black, while a value of `100%` leaves the input unchanged. 

[`contrast()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/contrast)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Adjusts the contrast of the drawing. A value of `0%` will create a drawing that is completely black. A value of `100%` leaves the drawing unchanged. 

[`drop-shadow()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/drop-shadow)
    
Applies a drop shadow effect to the drawing. A drop shadow is effectively a blurred, offset version of the drawing's alpha mask drawn in a particular color, composited below the drawing. This function takes up to five arguments: 

[`<offset-x>`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#offset-x)
    
See [`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length) for possible units. Specifies the horizontal distance of the shadow. 

[`<offset-y>`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#offset-y)
    
See [`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length) for possible units. Specifies the vertical distance of the shadow. 

[`<blur-radius>`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#blur-radius)
    
The larger this value, the bigger the blur, so the shadow becomes bigger and lighter. Negative values are not allowed. 

[`<color>`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#color)
    
See [`<color>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value) values for possible keywords and notations. 

[`grayscale()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/grayscale)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Converts the drawing to grayscale. A value of `100%` is completely grayscale. A value of `0%` leaves the drawing unchanged. 

[`hue-rotate()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/hue-rotate)
    
A CSS [`<angle>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle). Applies a hue rotation on the drawing. A value of `0deg` leaves the input unchanged. 

[`invert()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/invert)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Inverts the drawing. A value of `100%` means complete inversion. A value of `0%` leaves the drawing unchanged. 

[`opacity()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/opacity)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Applies transparency to the drawing. A value of `0%` means completely transparent. A value of `100%` leaves the drawing unchanged. 

[`saturate()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/saturate)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Saturates the drawing. A value of `0%` means completely un-saturated. A value of `100%` leaves the drawing unchanged. 

[`sepia()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/sepia)
    
A CSS [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage). Converts the drawing to sepia. A value of `100%` means completely sepia. A value of `0%` leaves the drawing unchanged. 

[`none`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter#none)
    
No filter is applied. Initial value.
