# WebGL2RenderingContext: drawArraysInstanced() method
Baseline 
Widely available
This feature is well established and works across many devices and browser versions. It’s been available across browsers since September 2021.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


**Note:** This feature is available in [Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API).
The **`WebGL2RenderingContext.drawArraysInstanced()`**method of the[WebGL 2 API](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) renders primitives from array data like the [`gl.drawArrays()`](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/drawArrays "gl.drawArrays\(\)") method. In addition, it can execute multiple instances of the range of elements.
**Note:** When using [WebGL 1](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext "WebGL 1"), the [`ANGLE_instanced_arrays`](https://developer.mozilla.org/en-US/docs/Web/API/ANGLE_instanced_arrays) extension can provide this method, too.

##  [Syntax](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#syntax)
###  [Parameters](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#parameters) 

[`mode`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#mode)
    
A [`GLenum`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Types "GLenum") specifying the type primitive to render. Possible values are:
  * `gl.POINTS`: Draws a single dot.
  * `gl.LINE_STRIP`: Draws a straight line to the next vertex.
  * `gl.LINE_LOOP`: Draws a straight line to the next vertex, and connects the last vertex back to the first.
  * `gl.LINES`: Draws a line between a pair of vertices.
  * [`gl.TRIANGLE_STRIP`](https://en.wikipedia.org/wiki/Triangle_strip "External link \(opens in new tab\)")
  * [`gl.TRIANGLE_FAN`](https://en.wikipedia.org/wiki/Triangle_fan "External link \(opens in new tab\)")
  * `gl.TRIANGLES`: Draws a triangle for a group of three vertices.



[`first`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#first)
    
A [`GLint`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Types "GLint") specifying the starting index in the array of vector points. 

[`count`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#count)
    
A [`GLsizei`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Types "GLsizei") specifying the number of indices to be rendered. 

[`instanceCount`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#instancecount)
    
A [`GLsizei`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Types "GLsizei") specifying the number of instances of the range of elements to execute.
###  [Return value](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext/drawArraysInstanced#return_value)
None ([`undefined`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/undefined)).
