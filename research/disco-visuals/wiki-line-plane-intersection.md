In [geometry](https://en.wikipedia.org/wiki/Geometry "Geometry"), the [intersection](https://en.wikipedia.org/wiki/Intersection "Intersection") of a [line](https://en.wikipedia.org/wiki/Line_\(mathematics\) "Line \(mathematics\)") and a [plane in three-dimensional space](https://en.wikipedia.org/wiki/Plane_in_three-dimensional_space "Plane in three-dimensional space") can be the [empty set](https://en.wikipedia.org/wiki/Empty_set "Empty set"), a [point](https://en.wikipedia.org/wiki/Point_\(geometry\) "Point \(geometry\)"), or the line itself. It is the entire line if that line is embedded in the plane, and is the empty set if the line is parallel to the plane but outside it. Otherwise, the line cuts through the plane at a single point.
Distinguishing these cases, and determining equations for the point and line in the latter cases, have use in [computer graphics](https://en.wikipedia.org/wiki/Computer_graphics "Computer graphics"), [motion planning](https://en.wikipedia.org/wiki/Motion_planning "Motion planning"), and [collision detection](https://en.wikipedia.org/wiki/Collision_detection "Collision detection").
## Algebraic form
[[edit](https://en.wikipedia.org/w/index.php?title=Line%E2%80%93plane_intersection&action=edit&section=1 "Edit section: Algebraic form")]
In [vector notation](https://en.wikipedia.org/wiki/Vector_notation "Vector notation"), a plane can be expressed as the set of points  p {\displaystyle \mathbf {p} } ![{\\displaystyle \\mathbf {p} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/dd73e3862cb92b016721b8c492eadb4e8a577527) for which      ( p − p 0 ) ⋅ n = 0 {\displaystyle (\mathbf {p} -\mathbf {p_{0}} )\cdot \mathbf {n} =0} ![{\\displaystyle \(\\mathbf {p} -\\mathbf {p_{0}} \)\\cdot \\mathbf {n} =0}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ab1a56a9f588e49135ad8f9d492bac96606abff0)
where  n {\displaystyle \mathbf {n} } ![{\\displaystyle \\mathbf {n} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/4a720c341f39f52fd96028dab83edd34d400be46) is a [normal vector](https://en.wikipedia.org/wiki/Normal_vector "Normal vector") to the plane and  p 0 {\displaystyle \mathbf {p_{0}} } ![{\\displaystyle \\mathbf {p_{0}} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/ca639d9feafabd7c3de9a9721ef714774ea380ba) is a point on the plane. (The notation  a ⋅ b {\displaystyle \mathbf {a} \cdot \mathbf {b} } ![{\\displaystyle \\mathbf {a} \\cdot \\mathbf {b} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/494aed3b5e94f1c0ee071debc707d2700c0e0390) denotes the [dot product](https://en.wikipedia.org/wiki/Dot_product "Dot product") of the vectors  a {\displaystyle \mathbf {a} } ![{\\displaystyle \\mathbf {a} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/1a957216653a9ee0d0133dcefd13fb75e36b8b9d) and  b {\displaystyle \mathbf {b} } ![{\\displaystyle \\mathbf {b} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/13ebf4628a1adf07133a6009e4a78bdd990c6eb9).)
The vector equation for a line is      p = l 0 + l d d ∈ R {\displaystyle \mathbf {p} =\mathbf {l_{0}} +\mathbf {l} \ d\quad d\in \mathbb {R} } ![{\\displaystyle \\mathbf {p} =\\mathbf {l_{0}} +\\mathbf {l} \\ d\\quad d\\in \\mathbb {R} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/920bf9e4d8271bcf9fc2c3e225cde892e7c6620a)
where  l {\displaystyle \mathbf {l} } ![{\\displaystyle \\mathbf {l} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/dca0b04733c4e44533df8a7eb12145d74cdbefef) is a [unit vector](https://en.wikipedia.org/wiki/Unit_vector "Unit vector") in the direction of the line,  l 0 {\displaystyle \mathbf {l_{0}} } ![{\\displaystyle \\mathbf {l_{0}} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/f92ce73822637973e6bfb3b1656c944d30202947) is a point on the line, and  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab) is a scalar in the [real number](https://en.wikipedia.org/wiki/Real_number "Real number") domain. Substituting the equation for the line into the equation for the plane gives      ( ( l 0 + l d ) − p 0 ) ⋅ n = 0. {\displaystyle ((\mathbf {l_{0}} +\mathbf {l} \ d)-\mathbf {p_{0}} )\cdot \mathbf {n} =0.} ![{\\displaystyle \(\(\\mathbf {l_{0}} +\\mathbf {l} \\ d\)-\\mathbf {p_{0}} \)\\cdot \\mathbf {n} =0.}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ec86041f93512f8831f51996dd9d125d514b4e16)
Expanding gives      ( l ⋅ n ) d + ( l 0 − p 0 ) ⋅ n = 0. {\displaystyle (\mathbf {l} \cdot \mathbf {n} )\ d+(\mathbf {l_{0}} -\mathbf {p_{0}} )\cdot \mathbf {n} =0.} ![{\\displaystyle \(\\mathbf {l} \\cdot \\mathbf {n} \)\\ d+\(\\mathbf {l_{0}} -\\mathbf {p_{0}} \)\\cdot \\mathbf {n} =0.}](https://wikimedia.org/api/rest_v1/media/math/render/svg/f7e12a2aa7c4100316459d3f0c07c2ac4b811fc8)
And solving for  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab) gives      d = ( p 0 − l 0 ) ⋅ n l ⋅ n . {\displaystyle d={(\mathbf {p_{0}} -\mathbf {l_{0}} )\cdot \mathbf {n} \over \mathbf {l} \cdot \mathbf {n} }.} ![{\\displaystyle d={\(\\mathbf {p_{0}} -\\mathbf {l_{0}} \)\\cdot \\mathbf {n}  \\over \\mathbf {l} \\cdot \\mathbf {n} }.}](https://wikimedia.org/api/rest_v1/media/math/render/svg/74828a6d17ad34b2bbb6f3760bce6b436a88bafb)
If  l ⋅ n = 0 {\displaystyle \mathbf {l} \cdot \mathbf {n} =0} ![{\\displaystyle \\mathbf {l} \\cdot \\mathbf {n} =0}](https://wikimedia.org/api/rest_v1/media/math/render/svg/826c3d32c2d6c6728e1b6b6a606ec00e5f98dca1) then the line and plane are parallel. There will be two cases: if  ( p 0 − l 0 ) ⋅ n = 0 {\displaystyle (\mathbf {p_{0}} -\mathbf {l_{0}} )\cdot \mathbf {n} =0} ![{\\displaystyle \(\\mathbf {p_{0}} -\\mathbf {l_{0}} \)\\cdot \\mathbf {n} =0}](https://wikimedia.org/api/rest_v1/media/math/render/svg/aba58b89ae8f93d2cf24435379b47ae4a7f7f88a) then the line is contained in the plane, that is, the line intersects the plane at each point of the line. Otherwise, the line and plane have no intersection.
If  l ⋅ n ≠ 0 {\displaystyle \mathbf {l} \cdot \mathbf {n} \neq 0} ![{\\displaystyle \\mathbf {l} \\cdot \\mathbf {n} \\neq 0}](https://wikimedia.org/api/rest_v1/media/math/render/svg/1bd5a1ba48c18488cdb291a6d3d6596ec494e237) there is a single point of intersection. The value of  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab) can be calculated and the point of intersection,  p {\displaystyle \mathbf {p} } ![{\\displaystyle \\mathbf {p} }](https://wikimedia.org/api/rest_v1/media/math/render/svg/dd73e3862cb92b016721b8c492eadb4e8a577527), is given by      p = l 0 + l d {\displaystyle \mathbf {p} =\mathbf {l_{0}} +\mathbf {l} \ d} ![{\\displaystyle \\mathbf {p} =\\mathbf {l_{0}} +\\mathbf {l} \\ d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a99d36b75b778453f9fd3c4c62fb6f3f1925f260).
## Parametric form
[[edit](https://en.wikipedia.org/w/index.php?title=Line%E2%80%93plane_intersection&action=edit&section=2 "Edit section: Parametric form")]
[![](https://thumb.wikimedia.org/wikipedia/commons/thumb/e/e3/Line_plane.svg/330px-Line_plane.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Line_plane.svg)The intersection of line and plane
A line is described by all points that are a given direction from a point. A general point on a line passing through points  l a = ( x a , y a , z a ) {\displaystyle \mathbf {l} _{a}=(x_{a},y_{a},z_{a})} ![{\\displaystyle \\mathbf {l} _{a}=\(x_{a},y_{a},z_{a}\)}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e32a6c2d7eb4e77670d865b95723e1572c3f603d) and  l b = ( x b , y b , z b ) {\displaystyle \mathbf {l} _{b}=(x_{b},y_{b},z_{b})} ![{\\displaystyle \\mathbf {l} _{b}=\(x_{b},y_{b},z_{b}\)}](https://wikimedia.org/api/rest_v1/media/math/render/svg/31e60274e94a2b9eaba061d6d347f841a61f5bd0) can be represented as       l a + l a b t , t ∈ R , {\displaystyle \mathbf {l} _{a}+\mathbf {l} _{ab}t,\quad t\in \mathbb {R} ,} ![{\\displaystyle \\mathbf {l} _{a}+\\mathbf {l} _{ab}t,\\quad t\\in \\mathbb {R} ,}](https://wikimedia.org/api/rest_v1/media/math/render/svg/08ed8a5b45accc9717f7857f33d009273aed4af2)
where  l a b = l b − l a {\displaystyle \mathbf {l} _{ab}=\mathbf {l} _{b}-\mathbf {l} _{a}} ![{\\displaystyle \\mathbf {l} _{ab}=\\mathbf {l} _{b}-\\mathbf {l} _{a}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/08e1ab3e9234b16c017138c5c7a686dd5f1dc9db) is the vector pointing from  l a {\displaystyle \mathbf {l} _{a}} ![{\\displaystyle \\mathbf {l} _{a}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/24c63bac32ab4357b8e058003cf22074e9441187) to  l b {\displaystyle \mathbf {l} _{b}} ![{\\displaystyle \\mathbf {l} _{b}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/3bcbded2eb4a4a04f565dd5c1c44f4c4a569492d).
Similarly a general point on a plane determined by the triangle defined by the points  p 0 = ( x 0 , y 0 , z 0 ) {\displaystyle \mathbf {p} _{0}=(x_{0},y_{0},z_{0})} ![{\\displaystyle \\mathbf {p} _{0}=\(x_{0},y_{0},z_{0}\)}](https://wikimedia.org/api/rest_v1/media/math/render/svg/86353058967f318f37cd37c9932762742accd2d6),  p 1 = ( x 1 , y 1 , z 1 ) {\displaystyle \mathbf {p} _{1}=(x_{1},y_{1},z_{1})} ![{\\displaystyle \\mathbf {p} _{1}=\(x_{1},y_{1},z_{1}\)}](https://wikimedia.org/api/rest_v1/media/math/render/svg/1486b7389012f41db31fdb55c0c0bb3e67ba68aa) and  p 2 = ( x 2 , y 2 , z 2 ) {\displaystyle \mathbf {p} _{2}=(x_{2},y_{2},z_{2})} ![{\\displaystyle \\mathbf {p} _{2}=\(x_{2},y_{2},z_{2}\)}](https://wikimedia.org/api/rest_v1/media/math/render/svg/75c11af2b1e0706cf0faf479edc90d058749594c) can be represented as      p 0 + p 01 u + p 02 v , u , v ∈ R , {\displaystyle \mathbf {p} _{0}+\mathbf {p} _{01}u+\mathbf {p} _{02}v,\quad u,v\in \mathbb {R} ,} ![{\\displaystyle \\mathbf {p} _{0}+\\mathbf {p} _{01}u+\\mathbf {p} _{02}v,\\quad u,v\\in \\mathbb {R} ,}](https://wikimedia.org/api/rest_v1/media/math/render/svg/faa06cc3bf3130dc9cc676b38205c34bbd794c5e)
where  p 01 = p 1 − p 0 {\displaystyle \mathbf {p} _{01}=\mathbf {p} _{1}-\mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{01}=\\mathbf {p} _{1}-\\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e21bc01ee1ae2a51c3c1d3561e1957a1b0b0d121) is the vector pointing from  p 0 {\displaystyle \mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ae6eb9d63094845ac7406038dc1ed8803f6ef575) to  p 1 {\displaystyle \mathbf {p} _{1}} ![{\\displaystyle \\mathbf {p} _{1}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/279e30b6f8eba8d6ff75f984f9393eebc2ea6d6e), and  p 02 = p 2 − p 0 {\displaystyle \mathbf {p} _{02}=\mathbf {p} _{2}-\mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{02}=\\mathbf {p} _{2}-\\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a9324b8f2ebcba497d7af49e4f22f8cfbbc868c2) is the vector pointing from  p 0 {\displaystyle \mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ae6eb9d63094845ac7406038dc1ed8803f6ef575) to  p 2 {\displaystyle \mathbf {p} _{2}} ![{\\displaystyle \\mathbf {p} _{2}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/0503cf42886fcd7909a39b737ba760b0249b3ecf).
The point at which the line intersects the plane is therefore described by setting the point on the line equal to the point on the plane, giving the [parametric equation](https://en.wikipedia.org/wiki/Parametric_equation "Parametric equation"):      l a + l a b t = p 0 + p 01 u + p 02 v . {\displaystyle \mathbf {l} _{a}+\mathbf {l} _{ab}t=\mathbf {p} _{0}+\mathbf {p} _{01}u+\mathbf {p} _{02}v.} ![{\\displaystyle \\mathbf {l} _{a}+\\mathbf {l} _{ab}t=\\mathbf {p} _{0}+\\mathbf {p} _{01}u+\\mathbf {p} _{02}v.}](https://wikimedia.org/api/rest_v1/media/math/render/svg/7c2ff40b33ab73280cc733b4e82cdf156a6a4f27)
This can be rewritten as      l a − p 0 = − l a b t + p 01 u + p 02 v , {\displaystyle \mathbf {l} _{a}-\mathbf {p} _{0}=-\mathbf {l} _{ab}t+\mathbf {p} _{01}u+\mathbf {p} _{02}v,} ![{\\displaystyle \\mathbf {l} _{a}-\\mathbf {p} _{0}=-\\mathbf {l} _{ab}t+\\mathbf {p} _{01}u+\\mathbf {p} _{02}v,}](https://wikimedia.org/api/rest_v1/media/math/render/svg/839b29434f672dc5406b1799da8326121a39e971)
which can be expressed in matrix form as      [ l a − p 0 ] = [ − l a b p 01 p 02 ] [ t u v ] , {\displaystyle {\begin{bmatrix}\mathbf {l} _{a}-\mathbf {p} _{0}\end{bmatrix}}={\begin{bmatrix}-\mathbf {l} _{ab}&\mathbf {p} _{01}&\mathbf {p} _{02}\end{bmatrix}}{\begin{bmatrix}t\\\u\\\v\end{bmatrix}},} ![{\\displaystyle {\\begin{bmatrix}\\mathbf {l} _{a}-\\mathbf {p} _{0}\\end{bmatrix}}={\\begin{bmatrix}-\\mathbf {l} _{ab}&\\mathbf {p} _{01}&\\mathbf {p} _{02}\\end{bmatrix}}{\\begin{bmatrix}t\\\\u\\\\v\\end{bmatrix}},}](https://wikimedia.org/api/rest_v1/media/math/render/svg/3701d7c9c4c720ef96fa3fabfa96837e3fc2b403)
where the vectors are written as column vectors.
This produces a [system of linear equations](https://en.wikipedia.org/wiki/System_of_linear_equations "System of linear equations") which can be solved for  t {\displaystyle t} ![{\\displaystyle t}](https://wikimedia.org/api/rest_v1/media/math/render/svg/65658b7b223af9e1acc877d848888ecdb4466560),  u {\displaystyle u} ![{\\displaystyle u}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c3e6bb763d22c20916ed4f0bb6bd49d7470cffd8) and  v {\displaystyle v} ![{\\displaystyle v}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e07b00e7fc0847fbd16391c778d65bc25c452597). If the solution satisfies the condition  t ∈ [ 0 , 1 ] , {\displaystyle t\in [0,1],} ![{\\displaystyle t\\in \[0,1\],}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c327d1a07b1551a3ec5fc7bda0996d4ed770e462), then the intersection point is on the line segment between  l a {\displaystyle \mathbf {l} _{a}} ![{\\displaystyle \\mathbf {l} _{a}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/24c63bac32ab4357b8e058003cf22074e9441187) and  l b {\displaystyle \mathbf {l} _{b}} ![{\\displaystyle \\mathbf {l} _{b}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/3bcbded2eb4a4a04f565dd5c1c44f4c4a569492d), otherwise it is elsewhere on the line. Likewise, if the solution satisfies  u , v ∈ [ 0 , 1 ] , {\displaystyle u,v\in [0,1],} ![{\\displaystyle u,v\\in \[0,1\],}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c7f75527bca006732f85c0a50f7e05369a95de37), then the intersection point is in the [parallelogram](https://en.wikipedia.org/wiki/Parallelogram "Parallelogram") formed by the point  p 0 {\displaystyle \mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ae6eb9d63094845ac7406038dc1ed8803f6ef575) and vectors  p 01 {\displaystyle \mathbf {p} _{01}} ![{\\displaystyle \\mathbf {p} _{01}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/eaf699ff09e85d1e97dae17ae664d802cb62c490) and  p 02 {\displaystyle \mathbf {p} _{02}} ![{\\displaystyle \\mathbf {p} _{02}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c405dc68f4236eab73d1cd7ba2e8176b399adc29). If the solution additionally satisfies  ( u + v ) ≤ 1 {\displaystyle (u+v)\leq 1} ![{\\displaystyle \(u+v\)\\leq 1}](https://wikimedia.org/api/rest_v1/media/math/render/svg/3d7de14c8be152dd9c799bd4cd3401913d696b4b), then the intersection point lies in the triangle formed by the three points  p 0 {\displaystyle \mathbf {p} _{0}} ![{\\displaystyle \\mathbf {p} _{0}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/ae6eb9d63094845ac7406038dc1ed8803f6ef575),  p 1 {\displaystyle \mathbf {p} _{1}} ![{\\displaystyle \\mathbf {p} _{1}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/279e30b6f8eba8d6ff75f984f9393eebc2ea6d6e) and  p 2 {\displaystyle \mathbf {p} _{2}} ![{\\displaystyle \\mathbf {p} _{2}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/0503cf42886fcd7909a39b737ba760b0249b3ecf).
The determinant of the matrix can be calculated as      det ( [ − l a b p 01 p 02 ] ) = − l a b ⋅ ( p 01 × p 02 ) . {\displaystyle \det({\begin{bmatrix}-\mathbf {l} _{ab}&\mathbf {p} _{01}&\mathbf {p} _{02}\end{bmatrix}})=-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02}).} ![{\\displaystyle \\det\({\\begin{bmatrix}-\\mathbf {l} _{ab}&\\mathbf {p} _{01}&\\mathbf {p} _{02}\\end{bmatrix}}\)=-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\).}](https://wikimedia.org/api/rest_v1/media/math/render/svg/50e0e2f20d9aab7a2e6322d2ea71ae36bb52e21b)
If the determinant is zero, then there is no unique solution; the line is either in the plane or parallel to it.
If a unique solution exists (determinant is not 0), then it can be found by [inverting](https://en.wikipedia.org/wiki/Matrix_inversion#Inversion_of_3_%C3%97_3_matrices "Matrix inversion") the matrix and rearranging:      [ t u v ] = [ − l a b p 01 p 02 ] − 1 [ l a − p 0 ] , {\displaystyle {\begin{bmatrix}t\\\u\\\v\end{bmatrix}}={\begin{bmatrix}-\mathbf {l} _{ab}&\mathbf {p} _{01}&\mathbf {p} _{02}\end{bmatrix}}^{-1}{\begin{bmatrix}\mathbf {l} _{a}-\mathbf {p} _{0}\end{bmatrix}},} ![{\\displaystyle {\\begin{bmatrix}t\\\\u\\\\v\\end{bmatrix}}={\\begin{bmatrix}-\\mathbf {l} _{ab}&\\mathbf {p} _{01}&\\mathbf {p} _{02}\\end{bmatrix}}^{-1}{\\begin{bmatrix}\\mathbf {l} _{a}-\\mathbf {p} _{0}\\end{bmatrix}},}](https://wikimedia.org/api/rest_v1/media/math/render/svg/d96252e964490fb3a9055be3ea692923ae6bd9f0)
which expands to      [ t u v ] = 1 − l a b ⋅ ( p 01 × p 02 ) [ ( p 01 × p 02 ) T ( p 02 × − l a b ) T ( − l a b × p 01 ) T ] [ l a − p 0 ] {\displaystyle {\begin{bmatrix}t\\\u\\\v\end{bmatrix}}={\frac {1}{-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02})}}{\begin{bmatrix}{(\mathbf {p} _{01}\times \mathbf {p} _{02})}^{\mathrm {T} }\\\\{(\mathbf {p} _{02}\times -\mathbf {l} _{ab})}^{\mathrm {T} }\\\\{(-\mathbf {l} _{ab}\times \mathbf {p} _{01})}^{\mathrm {T} }\end{bmatrix}}{\begin{bmatrix}\mathbf {l} _{a}-\mathbf {p} _{0}\end{bmatrix}}} ![{\\displaystyle {\\begin{bmatrix}t\\\\u\\\\v\\end{bmatrix}}={\\frac {1}{-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}}{\\begin{bmatrix}{\(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}^{\\mathrm {T} }\\\\{\(\\mathbf {p} _{02}\\times -\\mathbf {l} _{ab}\)}^{\\mathrm {T} }\\\\{\(-\\mathbf {l} _{ab}\\times \\mathbf {p} _{01}\)}^{\\mathrm {T} }\\end{bmatrix}}{\\begin{bmatrix}\\mathbf {l} _{a}-\\mathbf {p} _{0}\\end{bmatrix}}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/be1c29d0400257950334ff9e2f65a17f323df23d)
and then to      [ t u v ] = 1 − l a b ⋅ ( p 01 × p 02 ) [ ( p 01 × p 02 ) ⋅ ( l a − p 0 ) ( p 02 × − l a b ) ⋅ ( l a − p 0 ) ( − l a b × p 01 ) ⋅ ( l a − p 0 ) ] , {\displaystyle {\begin{bmatrix}t\\\u\\\v\end{bmatrix}}={\frac {1}{-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02})}}{\begin{bmatrix}{(\mathbf {p} _{01}\times \mathbf {p} _{02})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})\\\\{(\mathbf {p} _{02}\times -\mathbf {l} _{ab})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})\\\\{(-\mathbf {l} _{ab}\times \mathbf {p} _{01})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})\end{bmatrix}},} ![{\\displaystyle {\\begin{bmatrix}t\\\\u\\\\v\\end{bmatrix}}={\\frac {1}{-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}}{\\begin{bmatrix}{\(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)\\\\{\(\\mathbf {p} _{02}\\times -\\mathbf {l} _{ab}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)\\\\{\(-\\mathbf {l} _{ab}\\times \\mathbf {p} _{01}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)\\end{bmatrix}},}](https://wikimedia.org/api/rest_v1/media/math/render/svg/71925c0b78c46579a41f4c7c3bc37a96d8ab1743)
thus giving the solutions:      t = ( p 01 × p 02 ) ⋅ ( l a − p 0 ) − l a b ⋅ ( p 01 × p 02 ) {\displaystyle t={\frac {{(\mathbf {p} _{01}\times \mathbf {p} _{02})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})}{-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02})}}} ![{\\displaystyle t={\\frac {{\(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)}{-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/d15c7464a9a3c25c55a13d964fe37d38a3648f94)      u = ( p 02 × − l a b ) ⋅ ( l a − p 0 ) − l a b ⋅ ( p 01 × p 02 ) {\displaystyle u={\frac {{(\mathbf {p} _{02}\times -\mathbf {l} _{ab})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})}{-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02})}}} ![{\\displaystyle u={\\frac {{\(\\mathbf {p} _{02}\\times -\\mathbf {l} _{ab}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)}{-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/3ece713463bcca14445cb33405e3d706a6c1c570)      v = ( − l a b × p 01 ) ⋅ ( l a − p 0 ) − l a b ⋅ ( p 01 × p 02 ) . {\displaystyle v={\frac {{(-\mathbf {l} _{ab}\times \mathbf {p} _{01})}\cdot (\mathbf {l} _{a}-\mathbf {p} _{0})}{-\mathbf {l} _{ab}\cdot (\mathbf {p} _{01}\times \mathbf {p} _{02})}}.} ![{\\displaystyle v={\\frac {{\(-\\mathbf {l} _{ab}\\times \\mathbf {p} _{01}\)}\\cdot \(\\mathbf {l} _{a}-\\mathbf {p} _{0}\)}{-\\mathbf {l} _{ab}\\cdot \(\\mathbf {p} _{01}\\times \\mathbf {p} _{02}\)}}.}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e5c50a94982aa66a0c835784395453e42f200a4c)
The point of intersection is then equal to      l a + l a b t {\displaystyle \mathbf {l} _{a}+\mathbf {l} _{ab}t} ![{\\displaystyle \\mathbf {l} _{a}+\\mathbf {l} _{ab}t}](https://wikimedia.org/api/rest_v1/media/math/render/svg/38997b16f5cdfec3abcc563b1733d30b4026f013)
## Uses
[[edit](https://en.wikipedia.org/w/index.php?title=Line%E2%80%93plane_intersection&action=edit&section=3 "Edit section: Uses")]
In the [ray tracing](https://en.wikipedia.org/wiki/Ray_tracing_\(graphics\) "Ray tracing \(graphics\)") method of [computer graphics](https://en.wikipedia.org/wiki/Computer_graphics "Computer graphics") a surface can be represented as a set of pieces of planes. The intersection of a ray of light with each plane is used to produce an image of the surface. In vision-based [3D reconstruction](https://en.wikipedia.org/wiki/3D_reconstruction "3D reconstruction"), a subfield of [computer vision](https://en.wikipedia.org/wiki/Computer_vision "Computer vision"), depth values are commonly measured by so-called triangulation method, which finds the intersection between light plane and ray reflected toward camera.
The algorithm can be generalised to cover intersection with other planar figures, in particular, the [intersection of a polyhedron with a line](https://en.wikipedia.org/wiki/Intersection_of_a_polyhedron_with_a_line "Intersection of a polyhedron with a line").
