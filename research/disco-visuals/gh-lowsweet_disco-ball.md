# Disco Ball
[](https://github.com/lowsweet/disco-ball#disco-ball)
_For when you’re feeling nostalgic, or just want to vibe._
A procedural mirror ball with a halo, stage spotlights and moving background reflections. Vanilla JavaScript + Three.js + Canvas. Extracted from the lighting modules of [my personal website](https://liushixian.design) into a self-contained, runnable example.
[中文说明](https://github.com/lowsweet/disco-ball/blob/main/README.zh-CN.md) · [Sources & licenses](https://github.com/lowsweet/disco-ball/blob/main/THIRD_PARTY.md)
disco-light.mp4
## Run
[](https://github.com/lowsweet/disco-ball#run)
Node **22.12+** , npm. No API keys or external services.

```
npm ci
npm run dev
# Production output in dist/
npm run build
npm run preview
```

Pause / Resume controls the animation. Mirror ball, halo, spotlights and background reflections can be switched separately. Reduced-motion mode shows a static composition; hidden pages stop their animation loop. The demonstration uses a static pastel sky background.
## Use in another Vite page
[](https://github.com/lowsweet/disco-ball#use-in-another-vite-page)
Copy the effect modules and their `assets` directory together. Include `style.css` (or adapt its canvas stacking rules) and give the container a nonzero size:

```
import { mountDisco } from './demo.js';
const effect = mountDisco(document.querySelector('#stage'), {
  onStatus: message => { document.querySelector('#status').textContent = message; }
});
effect.setOptions({ paused: true });
effect.setOptions({ paused: false, spots: false });
// On unmount:
effect.dispose();
```

Options: `enabled`, `paused`, `ball`, `aura`, `beams`, `spots` (booleans). All effects default on, paused defaults off. This is an example-level API, not a published npm component library. A graphics failure shows a message; reload to retry.
## How it works
[](https://github.com/lowsweet/disco-ball#how-it-works)
  * `disco-ball.js`: procedural mirror tiles, HDR reflections, orthographic top-mounted camera, rotation and projection geometry.
  * `disco-aura.js` / `disco-spotlights.js`: Canvas halo and separate front/back beams.
  * `disco-sky-projection.js` / `disco-sky-config.js`: local pre-rendered light artwork, composed at runtime.
  * `disco-background.js`: static pastel sky composition without animated light bands.
  * `demo.js`: a single animation clock, controls, resize, visibility, reduced motion and teardown.


Drawing pixel ratio is capped at 1.5. Narrow screens use lower-resolution internal projection textures; Canvas effects retain their original resolution caps. Pausing freezes the clock without resetting it. Disposing stops listeners/observers/frames and releases scene resources.

```
npm run render:disco-sky
```

This regenerates the background reflection artwork and writes diagnostics to ignored `output/`.
## Differences from my personal website
[](https://github.com/lowsweet/disco-ball#differences-from-my-personal-website)
The demo retains the rotation and lighting modules, shows the complete ball and uses a static pastel sky with a whole-sphere warm overlay. The active environment is a PNG I edited converted to Radiance RGBE; conversion does not recover the original HDR dynamic range. No laptop receives projected light.
See [verification notes](https://github.com/lowsweet/disco-ball/blob/main/docs/VERIFICATION.md) and [asset licenses](https://github.com/lowsweet/disco-ball/blob/main/THIRD_PARTY.md). Project code is MIT; asset terms are listed separately. No Pages deployment or npm publication is configured.
## CI setup
[](https://github.com/lowsweet/disco-ball#ci-setup)
The build workflow template is in `docs/ci/build.yml`. Move it to `.github/workflows/build.yml` using a GitHub credential with workflow-write permission to enable Actions. The publishing credential could not create workflow files, so automated CI is not active yet. Local clean builds passed.
