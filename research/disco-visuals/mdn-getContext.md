# HTMLCanvasElement: getContext() method
Baseline 
Widely available
*
This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.
* Some parts of this feature may have varying levels of support. 
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


The **`HTMLCanvasElement.getContext()`**method returns a drawing context on the canvas, or[`null`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/null) if the context identifier is not supported, or the canvas has already been set to a different context mode.
Later calls to this method on the same canvas element, with the same `contextType` argument, will always return the same drawing context instance as was returned the first time the method was invoked. It is not possible to get a different drawing context object on a given canvas element.

###  [Parameters](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#parameters) 

[`contextType`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#contexttype)
    
A string containing the context identifier defining the drawing context associated to the canvas. Possible values are: 

[`"2d"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#2d)
    
Creates a [`CanvasRenderingContext2D`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D) object representing a two-dimensional rendering context. 

[`"webgl"` (or `"experimental-webgl"`)](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#webgl)
    
Creates a [`WebGLRenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext) object representing a three-dimensional rendering context. This context is only available on browsers that implement [WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) version 1 (OpenGL ES 2.0). 

[`"webgl2"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#webgl2)
    
Creates a [`WebGL2RenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext) object representing a three-dimensional rendering context. This context is only available on browsers that implement [WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API) version 2 (OpenGL ES 3.0). 

[`"webgpu"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#webgpu)
    
Creates a [`GPUCanvasContext`](https://developer.mozilla.org/en-US/docs/Web/API/GPUCanvasContext) object representing a three-dimensional rendering context for WebGPU render pipelines. This context is only available on browsers that implement [The WebGPU API](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API). 

[`"bitmaprenderer"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#bitmaprenderer)
    
Creates an [`ImageBitmapRenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/ImageBitmapRenderingContext) which only provides functionality to replace the content of the canvas with a given [`ImageBitmap`](https://developer.mozilla.org/en-US/docs/Web/API/ImageBitmap).
**Note:** The identifier `"experimental-webgl"` is used in new implementations of WebGL. These implementations have either not reached test suite conformance, or the graphics drivers on the platform are not yet stable. The [Khronos Group](https://www.khronos.org/ "External link \(opens in new tab\)") certifies WebGL implementations under certain [conformance rules](https://registry.khronos.org/webgl/sdk/tests/CONFORMANCE_RULES.txt "External link \(opens in new tab\)"). 

[`contextAttributes` Optional](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#contextattributes)
    
You can use several context attributes when creating your rendering context, for example:
2d context attributes: 

[`alpha`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#alpha)
    
A boolean value that indicates if the canvas contains an alpha channel. If set to `false`, the browser now knows that the backdrop is always opaque, which can speed up drawing of transparent content and images. 

[`colorSpace` Optional](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#colorspace)
    
Specifies the color space of the rendering context. Possible values are:
  * `"srgb"` selects the [sRGB color space](https://en.wikipedia.org/wiki/SRGB "External link \(opens in new tab\)"). This is the default value.
  * `"display-p3"` selects the [display-p3 color space](https://en.wikipedia.org/wiki/DCI-P3 "External link \(opens in new tab\)").



[`colorType` Optional](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#colortype)
    
Specifies the color type of the rendering context. Possible values are:
  * `"unorm8"` sets the color channels to 8 bit unsigned values. This is the default value.
  * `"float16"` sets the color channels to 16-bit floating-point values.



[`desynchronized`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#desynchronized)
    
A boolean value that hints the user agent to reduce the latency by desynchronizing the canvas paint cycle from the event loop. 

[`willReadFrequently`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#willreadfrequently)
    
A boolean value that indicates whether or not a lot of read-back operations are planned. This will force the use of a software (instead of hardware accelerated) 2D canvas and can save memory when calling [`getImageData()`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/getImageData "getImageData\(\)") frequently.
WebGL context attributes: 

[`alpha`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#alpha_2)
    
A boolean value that indicates if the canvas contains an alpha buffer. 

[`depth`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#depth)
    
A boolean value that indicates that the drawing buffer is requested to have a depth buffer of at least 16 bits. 

[`stencil`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#stencil)
    
A boolean value that indicates that the drawing buffer is requested to have a stencil buffer of at least 8 bits. 

[`desynchronized`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#desynchronized_2)
    
A boolean value that hints the user agent to reduce the latency by desynchronizing the canvas paint cycle from the event loop. 

[`antialias`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#antialias)
    
A boolean value that indicates whether or not to perform anti-aliasing if possible. 

[`failIfMajorPerformanceCaveat`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#failifmajorperformancecaveat)
    
A boolean value that indicates if a context will be created if the system performance is low or if no hardware GPU is available. 

[`powerPreference`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#powerpreference)
    
A hint to the user agent indicating what configuration of GPU is suitable for the WebGL context. Possible values are: 

[`"default"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#default)
    
Let the user agent decide which GPU configuration is most suitable. This is the default value. 

[`"high-performance"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#high-performance)
    
Prioritizes rendering performance over power consumption. 

[`"low-power"`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#low-power)
    
Prioritizes power saving over rendering performance. 

[`premultipliedAlpha`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#premultipliedalpha)
    
A boolean value that indicates that the page compositor will assume the drawing buffer contains colors with pre-multiplied alpha. 

[`preserveDrawingBuffer`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#preservedrawingbuffer)
    
If the value is true the buffers will not be cleared and will preserve their values until cleared or overwritten by the author. 

[`xrCompatible`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#xrcompatible)
    
A boolean value that hints to the user agent to use a compatible graphics adapter for an [immersive XR device](https://developer.mozilla.org/en-US/docs/Web/API/WebXR_Device_API). Setting this synchronous flag at context creation is discouraged; rather call the asynchronous [`WebGLRenderingContext.makeXRCompatible()`](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/makeXRCompatible) method the moment you intend to start an XR session.
**Note:** The WebGPU specification does not define any specific context attributes for `getContext()`. Instead, it provides configuration options via the [`GPUCanvasContext.configure()`](https://developer.mozilla.org/en-US/docs/Web/API/GPUCanvasContext/configure) method.
###  [Return value](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#return_value)
A rendering context which is either a
  * [`CanvasRenderingContext2D`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D) for `"2d"`,
  * [`WebGLRenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext) for `"webgl"` and `"experimental-webgl"`,
  * [`WebGL2RenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext) for `"webgl2"`,
  * [`GPUCanvasContext`](https://developer.mozilla.org/en-US/docs/Web/API/GPUCanvasContext) for `"webgpu"`,
  * [`ImageBitmapRenderingContext`](https://developer.mozilla.org/en-US/docs/Web/API/ImageBitmapRenderingContext) for `"bitmaprenderer"`.


If the context identifier is not supported, or the canvas has already been set to a different context mode, `null` is returned.
###  [Exceptions](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext#exceptions) 

`InvalidStateError` [`DOMException`](https://developer.mozilla.org/en-US/docs/Web/API/DOMException) 
    
Throws if the canvas has transferred its control to offscreen by calling [`HTMLCanvasElement.transferControlToOffscreen()`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/transferControlToOffscreen).
