# Import website assets into a Brand Library (Web App)
How to import logos, colors, fonts, and more from a website into your Photoroom Brand Library. Web App.
C
Written by Craig Wright
Updated this week

A quick way to set up a Brand Library is to use Photoroom's **Import from website** feature. It lets you enter a web site address and then Photoroom automatically imports the brand assets from the website into your Brand Library. These include:
  * Logos
  * Color schemes (imported as a palette)
  * Google fonts
  * Brand information
  * Instagram handle.   
​

**Import brand** is currently only available on the Web App version of Photoroom.

# Steps (Web App)
To import brand assets from your website:
  1. Log in at [app.photoroom.com](https://app.photoroom.com).
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in.
  3. Select **Brand Library**.
  4. Select **Import from website**. 
  5. Enter the web address (URL) of your website.
  6. Select **Import**.  
Photoroom automatically detects brand assets on your website.   
​  
​**Note:** If Photoroom cannot import the fonts, it displays a message to let you know. You will need to import the fonts manually (see [Add fonts to your brand kit](https://help.photoroom.com/en/articles/10174664-add-fonts-to-your-brand-kit)).  
​
  7. Look at the Profile on the import dialog to see what brand assets Photoroom has detected. If you're happy with those, select **Add to Brand Library** to import them.


The detected brand assets are imported and added to the Brand Library for the Space. Everyone working in the Space can use the assets in the Brand Library, for example, they can all add logos from the Brand Library.

# Troubleshooting
## Banner with Import from website option is not shown
If **Import from website** is not shown, try:
  * Opening a design in the editor and selecting Brand Library. Use the Import your brand box at the top of the Brand Library column instead.  
​
[![Screenshot showing Brand Library selected when a design is being edited. The import your brand section is shown at the top of the Brand Library sidebar.](https://downloads.intercomcdn.com/i/o/h69nsblw/2765136678/9000c0215911ae2444500e18bb96/alt-import-brandlibrary-web.png?expires=1794121200&signature=63d69d6dc30f6a8e90b5e1a692038d697bc6775bd2ded12363bf7336ae13c15e&req=dichE8h9m4dYUfMW1HO4zTRKCU1UyrThE77KzO%2BR1O73hNSPQAQXFOrv8u5Z%0AxmXY%0A)](https://downloads.intercomcdn.com/i/o/h69nsblw/2765136678/9000c0215911ae2444500e18bb96/alt-import-brandlibrary-web.png?expires=1794121200&signature=63d69d6dc30f6a8e90b5e1a692038d697bc6775bd2ded12363bf7336ae13c15e&req=dichE8h9m4dYUfMW1HO4zTRKCU1UyrThE77KzO%2BR1O73hNSPQAQXFOrv8u5Z%0AxmXY%0A)
  
​
  * Opening Photoroom in a different browser, a private window or on another computer, and sign in. The banner and card reappear there.
  * Clearing the cache and cookies for your web browser. This also signs you out and resets other dismissed banners.


You can also import content into your Brand Library manually by selecting **Brand Library** and then using the **+ Add** options in each section. 
## Photoroom did not import other social media handles
The Brand Library import feature only imports Instagram handles. It does not import other social media profiles and handles.
