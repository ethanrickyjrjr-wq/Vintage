# Remove a background or extract an image in Preview on Mac
You can remove the background from an image, or extract part of an image. For example, you can extract one person’s face from a group photo and then paste the face elsewhere.
[Open Preview for me](x-help-action://openApp?bundleId=com.apple.Preview)
## Remove the background from an image
  1. Go to the Preview app ![](https://ipcdn-web.apple.com/assets/v2/web/3e5e2316-e306-43e3-a386-e9205cc60981) on your Mac.
  2. [Open an image](https://support.apple.com/guide/preview/aside/glosea300deb/11.0/mac/27).
  3. Click ![the Remove Background button](https://ipcdn-web.apple.com/assets/v2/web/2e8f3c64-1e93-448e-abe3-8a8c0d4a983a).
  4. If you’re asked whether you want to convert the document to a PNG file, do one of the following:
     * _Make a copy of the original image:_ Click Cancel, then choose File > Duplicate.
     * _Convert the original image:_ Click Convert.
To undo the background removal, choose Edit > Undo.


## Extract an image
  1. Go to the Preview app ![](https://ipcdn-web.apple.com/assets/v2/web/3e5e2316-e306-43e3-a386-e9205cc60981) on your Mac.
  2. [Open an image](https://support.apple.com/guide/preview/aside/glosea300deb/11.0/mac/27).
  3. Click ![the Show Markup Toolbar button](https://ipcdn-web.apple.com/assets/v2/web/4c4b0389-2f72-45be-824b-957637c8abc5) (if the Markup toolbar isn’t showing), click ![the Selection Tools menu](https://ipcdn-web.apple.com/assets/v2/web/2d5bf481-9a24-4dc7-b06e-361f9ca51cbc), then choose ![the Smart Lasso tool](https://ipcdn-web.apple.com/assets/v2/web/eb3ff1a3-3dd0-44f9-ad1d-d67164e11314).
  4. Trace the edge of the image you want to extract.
Make sure the image’s edge is within the thick border that appears as you trace.
  5. Connect the end of the border back to its beginning, or stop dragging to connect the border in a straight line back to the beginning.
  6. Choose Edit > Copy to copy the image so that you can paste it in a document.


## Extract a PDF page as an image
You can select part of an image opened in Preview, then copy and paste it elsewhere or crop the content surrounding it. If the image is in a PDF, you need to extract the PDF page as an image before you can use the image markup tools.
  1. Go to the Preview app ![](https://ipcdn-web.apple.com/assets/v2/web/3e5e2316-e306-43e3-a386-e9205cc60981) on your Mac.
  2. [Open the PDF](https://support.apple.com/guide/preview/aside/glosea300deb/11.0/mac/27), choose View > Thumbnails, then select the page in the thumbnail sidebar.
  3. Click File > Export, type a name, [add a tag](https://support.apple.com/guide/mac-help/mchlp15236) (optional), then choose where you want to save it.
  4. Click the Format pop-up menu and choose an image format (such as PNG).
  5. Click Save.
