## Frequently asked questions
#### Who is the background removal API for?
Developers and teams who only need a clean cutout: marketplaces, retailers, delivery apps and photo tools processing images at scale. If you also need AI backgrounds, shadows, relighting or other edits in the same call, use the [Image Editing API](https://www.photoroom.com/api/edit-image) instead.
#### How much does the background removal API cost?
$0.02 per image on the Basic plan. You only pay for successful calls. For higher volumes, [Enterprise plans](https://www.photoroom.com/enterprise) offer custom pricing. Details are on our [pricing page](https://www.photoroom.com/api/pricing).
#### Which image formats are supported?
Input: PNG, JPEG, WEBP or HEIC, up to 50 MB and 6,000 px on the widest side. Output: PNG (the default, with a transparent background), JPEG or WEBP.
#### How do I integrate the background removal API?
[Get your API key](https://app.photoroom.com/api-dashboard), send it in the `x-api-key` header, and post your image to the endpoint:

```
curl --request POST \
  --url https://sdk.photoroom.com/v1/segment \
  --header 'x-api-key: YOUR_API_KEY' \
  --form image_file=@/path/to/your/image.jpg \
  --output photoroom-result.png
```

Ready-made code is available for JavaScript, Python, Node.js and iOS in the [documentation](https://docs.photoroom.com/remove-background-api-basic-plan/quickstart-guide).
#### Can I use an image URL instead of uploading a file?
Not with this API. It takes an uploaded file or a Base64-encoded image. To process images by URL, use the [Image Editing API](https://docs.photoroom.com/image-editing-api-plus-plan/quickstart-guide), which accepts an `imageUrl` parameter.
#### What should I do if I need help with the API?
Having trouble with the API? Join our [API community](https://photoroom.discourse.group/) to get help from our engineers, or check the [troubleshooting page](https://docs.photoroom.com/getting-started/troubleshooting) for common issues.
For anything billing-related or with sensitive information, please DM Photoroom directly in the community. We're always happy to help.
#### What are the rate limits?
60 images per minute by default. If you go over, the API returns a `429` error, so retry after a short pause. Enterprise plans can raise the limit for high-volume catalogs.
#### What output options can I set?
  * Output format: PNG, JPEG or WEBP.
  * Background: transparent, or any colour.
  * Size: preview, medium, HD or full resolution.
  * Crop: trim the result to the edges of the subject.
  * Green-screen clean-up: remove green edges left on the subject.


Every response also includes an [uncertainty score](https://docs.photoroom.com/remove-background-api-basic-plan/uncertainty-score), which flags images worth a human check.
#### What's the difference between this API and the Image Editing API?
This API removes backgrounds only, at $0.02 per image. The Image Editing API adds 20+ edits in one call, such as AI backgrounds, shadows, relighting and upscaling. One Image Editing call costs the same as five background removal calls.
#### I use Remove.bg's API. How do I switch?
Remove.bg's API shuts down on 1 Dec. Our [migration guide](https://www.photoroom.com/api/photoroom-vs-removebg) maps your existing calls to Photoroom, so you can [switch without rebuilding your integration](https://www.photoroom.com/api/photoroom-vs-removebg).
#### Can I remove backgrounds from Claude?
Yes. Connect the [Photoroom MCP to Claude](https://www.photoroom.com/api/claude), then ask in plain English, for example "remove the background from these product photos." Claude picks the right tool, runs it and returns the cutout. It works in Claude (desktop and web), Cowork and Claude Code on paid Claude plans.
