## FAQs
[More info in help center ](https://help.claid.ai/en/)
How many credits does each operation cost?
Please see the full list of operations available and their price in credits [here](https://help.claid.ai/en/article/how-many-credits-an-operation-costs-k4vepe/)
How many credits does it cost to process an image?
The number of credits you need to process an image would depend on the operations you would like to use. Please see the full list of operations and their prices in credits [here](https://help.claid.ai/en/article/how-many-credits-an-operation-costs-k4vepe/)
What's the difference between web plan credits and API credits?
They're two separate credit types with separate pools and pricing. Web (subscription) plan credits are used in the Claid web app; API credits power the image and video API and are billed per operation. They aren't interchangeable, and one can't be spent on the other.
Why did upscaling cost me more than 1 credit?
Upscaling cost in credits depends on the output size of the image you've processed. The bigger the image, the more credits it needs to be upscaled. You can find the image size to credits ratio [here](https://help.claid.ai/en/article/how-many-credits-an-operation-costs-k4vepe/)
How many credits does Image Resize and Crop cost?
Image Resize and Crop can be used for free if used together with any other operations
Do you offer volume discounts?
Yes. Custom enterprise plans include volume pricing, dedicated support, and SLAs. Talk to our team.
What's available in the self-serve API vs. enterprise?
The self-serve API covers the operations listed above at default limits. For higher volumes, custom workflows, fully managed processing, or capabilities beyond the standard API, custom [enterprise plans](https://claid.ai/enterprise-api) and [solutions](https://claid.ai/ai-native-agency) are built with our team. Talk to our team.
Can I get higher rate limits?
Default API request limits are 4 RPS / 120 RPM (some generation endpoints have lower limits). Higher limits are available on enterprise plans — talk to our team.
Is my data secure?
We're GDPR and CCPA compliant, encrypt data at rest and in transit, and never use customer data for model training. SOC 2 is in progress. For a security review or specifics, talk to our team.
