The NAD worry is fair for used clothing, because the buyer is paying for that exact garment, wear included. What seems to work for the sellers here: keep your real photos first and use the AI model shot as an extra, with a line in the description that it’s a styled example. Before using one, compare it side by side with the actual item at full zoom: colour, print placement, buttons, hem length and any flaws. If the AI version hides a mark or changes the fabric, drop it. That’s also the main thing to look for in a tool. With Katalogiq, for example, you generate the model shot from your own photo of the item, so it stays close to the real garment, but the side-by-side check is still worth doing every time. Add flat measurements so nobody judges fit from the model. Then watch your return reasons for a few weeks, so you know whether it actually helped.

I've been selling clothing online for about 3 years. Just recently, I began using ChatGPT to create 1 model photo for each listing and posted it along with many other photos of the actual item laying flat, on a mannequin, and also with a tape measure.  
  
In addition, I always include a note in the description, _"AI-generated model image included for styling inspiration only. The actual item may vary slightly in fit and appearance. Please read description and see listing photos for actual item."_  
  
What happened? When I updated the listings with the AI photo, I received more traffic and sales increased.   
  
Know that it took some time to figure out the prompts to use for ChatGPT. You need to be very specific -- describe what the model should look like along with their pose, what other clothes/jewelry they should be wearing, what the environment/setting is, what the vibe of the image is, the ratio of the image, etc. I also upload a description and images of the actual item including the measurements.  
  
So far, so good. But it's only been about 8 weeks since I added the model image. Time will tell.

I work in stages. I first check to make sure the cassette that is supposed to be in it, is actually the one in it. I then check to make sure the pad is there and secure. I will test ones worth at least $20 in the player for a few seconds. 
  

I won't list anything that is clearly in 'worn' or 'fair' condition, so everything gets graded as 'good' for the case, inlay, and cassette. This way when I set the template up for the AI, it applies those ratings to every cassette. Most will be far better than good condition and buyers are happy. As I am doing this condition check, I am sorting the cassettes into certain price points ($9.95 + free ship, $14.95 + free ship, and so on). On the ones I believe will be worth $20 or more, I will specifcially look those up to nail down a price. Each price point will be one batch through the AI, this way I do not have to go through and adjust prices. I did that one time and it took up too much time, so it easier to do when I'm sorting through the condition. I've sold enough cassettes to know in most cases which ones will have more value.
