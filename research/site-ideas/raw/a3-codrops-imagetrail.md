# Image Trail Effects
A set of brutalist effects for mouse-following image trails that show a random series of images.
[filter](https://tympanus.net/codrops/tag/filter/) [Motion Trail](https://tympanus.net/codrops/tag/motion-trail/)
[ ![](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_featured.jpg?x95600) ](https://tympanus.net/Development/ImageTrailEffects/ "Image Trail Effects Demo")
[Demo](https://tympanus.net/Development/ImageTrailEffects/) [Code](https://github.com/codrops/ImageTrailEffects/)
Today we’d like to share a fun mouse interaction effect with you that we found on the [VLNC Studio](http://www.vlnc.studio/) website. The idea is to follow the mouse and show a trail of random images. It’s a kind of brutalist effect and there are various possibilities when it comes to showing and hiding the images. So we compiled a set of demos that explores different animations.
The animations are powered by [TweenMax](https://greensock.com/tweenmax).
**Attention:** Note that the demos are experimental and that we use modern CSS properties that might not be supported in older browsers.
The main idea is to show the images quickly so that a trail forms along the movement of the mouse.
[![ImageTrailEffects_01](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_01.jpg?x95600)](https://tympanus.net/Development/ImageTrailEffects/index.html)
While there’s different ways to show the images, there’s also lots of room to play with the effects that make them disappear.
[![ImageTrailEffects_02](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_02.jpg?x95600)](https://tympanus.net/Development/ImageTrailEffects/index2.html)
Demo 3 shows how we can make the images “drop” when they disappear:
[![ImageTrailEffects_03](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_03.jpg?x95600)](https://tympanus.net/Development/ImageTrailEffects/index3.html)
We can also add a bit of a squeeze, too:
[![ImageTrailEffects_04](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_04.jpg?x95600)](https://tympanus.net/Development/ImageTrailEffects/index5.html)

The last demo explores setting the size of the image to be fullscreen and restricting the movement to the sides only:
[![ImageTrailEffects_05](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects_05.jpg?x95600)](https://tympanus.net/Development/ImageTrailEffects/index6.html)
This effect is inspired by [Ricky Michiels](https://www.rickymichiels.com/) website.
Here’s a short GIF that shows the effect of demo 2 where we scale the images up and fade them out:
![ImageTrailEffects.2019-08-07 11_22_55](https://tympanus.net/codrops/wp-content/uploads/2019/08/ImageTrailEffects.2019-08-07-11_22_55.gif?x95600)
We hope you enjoy these demos and find them useful.
