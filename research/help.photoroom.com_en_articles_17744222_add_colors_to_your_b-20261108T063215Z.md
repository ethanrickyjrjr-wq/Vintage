# Add colors to your Brand Library (Web App)
How to add brand colors to your Brand Library so that you can use the same colors consistently across your Space. Web App.
C
Written by Craig Wright
Updated this week

On the Web App version of Photoroom, you can add colors to your Brand Library in several ways. This article covers how to:
  * Create a color palette manually
  * Generate a color palette from an image
  * Generate a color palette from a layer in a design.


**Note:** You can also import brand colors automatically from your website. To find out how, see [Import website assets into a Brand Library (Web App)](https://help.photoroom.com/en/articles/17731485-import-website-assets-into-a-brand-library-web-app).
* * *
# Steps (Web App)
Follow the instructions in the sections below to create a new color palette in your Brand Library.
* * *
## Add a color palette to your Brand Library manually
To create a color palette and choose its colors manually:
  1. Log in at [app.photoroom.com](https://app.photoroom.com).
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in.
  3. Select **Brand Library**.
  4. In the **Colors** section, select **+ Add**.
  5. Select **Create your own** to add a new, untitled palette.
  6. Select the context menu ( **...** ) for your new palette and select **Rename**. 
  7. Give the palette a meaningful name and select **Rename** to confirm.
  8. Select the **plus +** icon in the new palette.
  9. Use the color selector to define a color and select **Add**.  
​  
To learn about the color selector, see [Color selectors (Web App)](https://help.photoroom.com/en/articles/13750719-color-selectors-web-app).   
​
  10. Repeat steps 8 and 9 until you have added all of the brand colors for the palette.


The color palettes in your Brand Library are shown as separate color palettes in the editors. This makes it easier to find your preferred colors. For details, see [Use Brand Library colors in a design (Web App)](https://help.photoroom.com/en/articles/17889217-use-brand-library-colors-in-a-design-web-app)
* * *
## Generate a color palette based on an image
To get Photoroom to generate a color palette automatically, based on the colors it detects in an image:
  1. Log in at [app.photoroom.com](https://app.photoroom.com).
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in.
  3. Select **Brand Library**.
  4. In the **Colors** section, select **+ Add**.
  5. Select **Generate from image**.
  6. Choose an image for Photoroom to analyze for colors, for example, a product photo.  
Photoroom analyzes the image and suggests a color palette.   
​
  7. Select **Add palette** to add the palette to your Brand Library.  
​  
If you don't want to add the palette, select **X** to close the Add a palette dialog. To create a color palette, you will need to start again from step 4.  
​ 
  8. Select the context menu ( **...** ) for the new color palette and then select **Rename**.
  9. Give the palette a meaningful name and select **Rename** to confirm.


The color palettes in your Brand Library are shown as separate color palettes in the editors. This makes it easier to find your preferred colors. For details, see [Use Brand Library colors in a design (Web App)](https://help.photoroom.com/en/articles/17889217-use-brand-library-colors-in-a-design-web-app)
* * *
## Generate a color palette based on a layer 
To get Photoroom to generate a color palette based on the colors in a selected layer:
  1. Log in at [app.photoroom.com](https://app.photoroom.com).
  2. Select the [Space](https://help.photoroom.com/en/articles/9183630-how-do-spaces-work) you want to work in.
  3. Select **Designs** and double-click on a design to open it in the editor.   
​  
Alternatively, you could use an image in a batch (Batch editor) or a product image (Product editor). To learn how to open these, see the articles in **Related content** at the end.  
​
  4. Select the layer that has colors you want to add to the Brand Library.
  5. Select **Save** at the top of the layer's settings.
  6. Select **Save colors**.
  7. Select **Add palette**.  
Photoroom generates a color palette based on the colors in the layer and adds it to your Brand Library.
  8. Select **Brand Library**.
  9. Select the context menu ( **...** ) for the new color palette and then **Rename**.
  10. Enter a name for the color palette and select **Rename** to confirm.


For details on how to use the colors, see [Use Brand Library colors in a design (Web App)](https://help.photoroom.com/en/articles/17889217-use-brand-library-colors-in-a-design-web-app)
