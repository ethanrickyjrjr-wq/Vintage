# Add and manage features for a Facebook group you admin

Group admins can choose which kinds of features are available in their group.
Admins can choose to allow or not allow features like [reels](https://www.facebook.com/help/630440174682282?helpref=hca), [music sharing](https://www.facebook.com/help/620049875737300?helpref=hca), [events](https://www.facebook.com/help/185716894811068?helpref=hca), [files](https://www.facebook.com/help/397856870259152?helpref=hca), [live videos](https://www.facebook.com/help/328627761448473?helpref=hca), [polls](https://www.facebook.com/help/175694272486085?helpref=hca), [guides](https://www.facebook.com/help/184985882229224?helpref=hca), [sales](https://www.facebook.com/help/1557451221155310?helpref=hca), [badges](https://www.facebook.com/help/383114938880295?helpref=hca) and GIFs.
Admins can also choose feature sets — curated collections of features, badges and tools — to add multiple features to their group at once. For example, the parenting feature set includes [anonymous posts](https://www.facebook.com/help/832270967369626?helpref=faq_content) and [badges](https://www.facebook.com/help/383114938880295?helpref=faq_content) like **Experienced parent** , while the [buy & sell feature set](https://www.facebook.com/help/776978302394267?helpref=faq_content) includes the **Sell something** post format and seller badges. When an admin adds a feature set, the group will automatically get new features as we add them to the set. Admins can remove any feature in the set, change the settings for any feature, turn off automatic updates or choose additional features to add to their group. Admins can choose more than one feature set.
## Features
**To add, remove or modify a feature:**
  1. Go to [facebook.com/groups](https://www.facebook.com/groups) and select your group.
  2. Click **Add Features** in the left menu, below **Group Settings**. 
     * To add a feature, click **Add** next to the feature.
     * To remove a feature, click **Settings** next to the feature then click **Remove**. 
     * To modify a feature, click **Settings** next to the feature then make your changes and click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=comet-exit-desktop&density=1)**Close**.


## Feature sets
**To add a feature set:**
  1. Go to [facebook.com/groups](https://www.facebook.com/groups) and select your group.
  2. Click **Add Features** in the left menu, below **Group Settings**.
  3. Scroll down to **Feature sets**. 
  4. You can view all the feature sets by clicking ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=fb-forwardchevron-desktop&density=1)**Next**. You can view more details about the set by clicking it.
  5. To add the set, click **Add set**.

**To remove a feature set:**
  1. Go to [facebook.com/groups](https://www.facebook.com/groups) and select your group.
  2. Click **Group Settings** in the left menu.
  3. Scroll down to **Added to group**.
  4. Click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=ofb-pencil-desktop&density=1)**Edit** next to **Added sets**. 
  5. Select the feature set and click **Remove**.
  6. Click **Remove set** to confirm.

**To modify a feature from a feature set:**
  1. Go to [facebook.com/groups](https://www.facebook.com/groups) and select your group.
  2. Click **Group Settings** in the left menu.
  3. Scroll down to **Added to group**.
  4. Click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=ofb-pencil-desktop&density=1)**Edit** next to the feature you want to modify. 
  5. Make your changes.
  6. Click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=comet-exit-desktop&density=1)**Close**.

**If you don't want to automatically get new features as we add them to the set:**
  1. Go to [facebook.com/groups](https://www.facebook.com/groups) and select your group.
  2. Click **Add Features** in the left menu, below **Group Settings**.
  3. Scroll down to **Feature sets**. 
  4. Click **Settings** below the feature set.
  5. Click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=fb-toggleonsettings-desktop&density=1)**Toggle** next to **Automatic updates**.
  6. Click ![](https://static.xx.fbcdn.net/assets/?set=content_operations_help_center&name=comet-exit-desktop&density=1)**Close**.
