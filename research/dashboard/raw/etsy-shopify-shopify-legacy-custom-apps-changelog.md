# 
Legacy custom apps can’t be created after January 1, 2026
Install AI ToolkitAsk about this pageCopy MD
DateOctober 30, 2025
FlagsChanged
SurfacesApps
**Update:** Starting January 1, 2026, you can no longer create new [custom apps](https://help.shopify.com/en/manual/apps/app-types/custom-apps) in the Shopify admin. This affects merchants and developers who create custom apps directly from the admin. Existing custom apps aren’t affected and will continue to work. To create a new custom app after this date, use the [Dev Dashboard](https://shopify.dev/docs/apps/build/dev-dashboard) to build the app, then install it on your store. This change improves security and long‑term support for custom apps.
