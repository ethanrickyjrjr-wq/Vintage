Hello @da702163,  
Yes, eBay's production API is generally intended for business use cases. However, you can still use eBay's APIs for educational and personal projects. You'll need to join the eBay Developers Program, which is free and provides access to various APIs. While there might be some limitations, it's definitely worth exploring for your purposes.
