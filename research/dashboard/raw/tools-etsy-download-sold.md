# How to Download a Spreadsheet of Your Sold Transactions 
You can download a record of your transactions as a spreadsheet CSV file. The CSV file is compatible with most spreadsheet applications, including Excel, Numbers, and Google Spreadsheets. 
To download a CSV file of currently for sale listings: 
  1. Sign into [Etsy.com](http://etsy.com) and go to **Shop Manager**.
  2. Select **Settings** , then select [**Options**](https://www.etsy.com/your/shops/me/options).
  3. Go to the **Download Data** tab.
  4. Select **Download CSV** under **Currently for Sale Listings**.


To download a CSV file of order items, orders, Etsy Payments sales or Etsy Payments deposits: 
  1. Sign into [Etsy.com](http://etsy.com) and go to **Shop Manager**.
  2. Select **Settings** , then select [**Options**](https://www.etsy.com/your/shops/me/options).
  3. Go to the **Download Data** tab.
  4. Go to **Orders.**
  5. Use the dropdown menus to select the **CSV Type** , **Month** and **Year**. To download a CSV for an entire year, don’t select **Month**.
  6. Select **Download CSV**. 


This spreadsheet will include a list of all your orders, including:
  * Payment method 


  * Item price 


  * Item title  
  

  * SKU numbers of items if you've added them


If you’re in the US or UK, you can also view and export data with [QuickBooks Self-Employed](https://quickbooks.intuit.com/partners/etsy/?utm_source=etsy&utm_medium=web&utm_content=helpUS&cid=par_etsy_US_helpUSQBSE#for-small-businesses).
