# ServiceWorkerGlobalScope: push event
Baseline 
Widely available
This feature is well established and works across many devices and browser versions. It’s been available across browsers since March 2023.
  * [ See full compatibility ](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/push_event#browser_compatibility)
  * [ Learn more ](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)


**Secure context:** This feature is available only in [secure contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts) (HTTPS), in some or all [supporting browsers](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/push_event#browser_compatibility).
**Note:** This feature is only available in [Service Workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API).
The **`push`**event is sent to a service worker's global scope (represented by the[`ServiceWorkerGlobalScope`](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope) interface) when the service worker has received a push message.
This event is not cancelable and does not bubble.
