## [Action#](https://ui.shadcn.com/docs/components/base/toast#action)
Pass button props with `actionProps` to render an action.

```
Copyconst id = toast.add({
  title: "Event created",
  actionProps: {
    children: "Undo",
    onClick() {
      toast.close(id)
    },
  },
})
```
