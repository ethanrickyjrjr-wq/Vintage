# How to Use Etsy’s API 
**Quick Answer**
Etsy has a public API that sellers and developers can use to build applications and connect shop data to tools, automations, and workflows. Go to the [Developer Portal](http://etsy.com/developers) to get started.

## What is Etsy’s API?
An API (Application Programming Interface) is a set of rules that enable different software applications to communicate and transfer data. Etsy has a public API that sellers and developers can use to build applications and connect shop data to tools, automations, and workflows.
To build with Etsy’s API, you need to register an app in the [Etsy Developer Portal](http://etsy.com/developers). Registering an app creates an Etsy App API keystring and a shared secret, which you can find in **Your Apps**.
## How do I register an app?
There are 2 main paths for registering an app:   
| [**Seller App**](https://help.etsy.com/hc/articles/41741508856471?segment=selling)  | **Personal App/Commercial Access**  |  
| --- | --- |  
| 
  * Connect your own shop data to custom tools, automations, or workflows
  * Short application
  * Eligible sellers who register their app are usually approved within minutes

 | 
  * Build applications that other sellers will use 
  * More detailed application and review process to ensure third-party apps meet Etsy’s standards
  * Start by registering a personal app, and once the app is ready for broader seller use, request Commercial API Access for that same app in the [Developer Portal](http://etsy.com/developers)

 |  
To register an app, go to the [Developer Portal](http://etsy.com/developers) and sign into your Etsy account. Select **Get started** and follow the instructions.
If approved, you will need to agree to the [API Terms of Use](https://www.etsy.com/legal/api).
### **Eligibility**
Eligibility depends on the type of app you're registering.
You may be eligible to register a seller app if you: 
  * Have an active Etsy shop in good standing
  * Do not already have a registered app


You may be eligible to register a personal app if you: 
  * Have a qualifying use case for building or testing an app beyond your own shop, including tools that other buyers or sellers may use at a limited scale


You may be eligible to request commercial access if you: 
  * Have an approved personal app
  * Have a qualifying commercial application that will be used by other Etsy sellers at a broader scale


## Frequently asked questions
How do I know which type of app is right for me? 
[Seller apps](https://help.etsy.com/hc/articles/41741508856471?segment=selling) are for individual Etsy sellers who want to connect an app to their own shop data. This is the recommended starting point if you are a shop owner building custom tools, automations, reports, or workflows for your shop only.
A personal app is the starting point for developers who want to build on Etsy’s API for uses beyond their own shop. This includes tools that other buyers or sellers may use at a limited scale. If your app needs to grow beyond limited-scale use, you can request an upgrade to Commercial Access.
What if I have additional questions about Etsy’s API? 
Learn more in the [Etsy API developer guide](https://developers.etsy.com/documentation/).

Here are some answers to common questions for users and developers of apps on Etsy
I want to add or disconnect an app
To connect an app to your shop:
  1. On [Etsy.com](http://Etsy.com), go to your [**Shop Manager**](https://www.etsy.com/your/shops/me/dashboard)**.**
  2. Choose **Apps**.
  3. In the **Browse all** tab, choose the app you’re interested in.
  4. Choose**Learn more** on the app page to visit the developer’s website.
  5. Create an account from the developer’s website and follow the steps to connect the app to your Etsy shop.


The process for adding an app to your shop is determined by the third-party developer who created it. Reach out to the developer via the contact link on their website if you need assistance, or have any other questions about their app.
To disconnect an app:
  1. On [Etsy.com](http://Etsy.com), go to your [**Shop Manager**](https://www.etsy.com/your/shops/me/dashboard)**.**
  2. Choose **Apps**.
  3. Select the **Connected apps** tab.
  4. Find the app you want to remove and select **Disconnect.**


I'm a developer and want to apply for an API key 
Etsy has a public API that sellers and developers can use to build applications and connect shop data to tools, automations, and workflows. Register for a seller app if you only need access to your own shop’s data, including listing, orders, inventory, and more. If you’re a developer building tools for other sellers, register a personal app, then apply for commercial access. 
To register an app: 
  1. Go to the [Etsy Developer Portal](http://Etsy.com/developers). 
  2. Select **Get started**. 
  3. Fill in the required fields to the best of your ability. 


Your request will be reviewed according to [Etsy's API Terms of Use](https://www.etsy.com/legal/api).
