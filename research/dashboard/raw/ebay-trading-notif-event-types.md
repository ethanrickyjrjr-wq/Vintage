# NotificationEventTypeCodeType ( [token](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/types/simpletypes.html#token) )
Enumerated type that contains the complete list of platform notifications that can be sent out to subscribed users, servers, or applications. Some notifications are only sent to buyers or sellers, and some are sent to both buyers and sellers. 
Types that use NotificationEventTypeCodeType:
[NotificationDetailsType](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/types/NotificationDetailsType.html), [NotificationEnableType](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/types/NotificationEnableType.html), [NotificationEventPropertyType](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/types/NotificationEventPropertyType.html)


Calls that use one or more values of NotificationEventTypeCodeType:
[GetNotificationPreferences](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/GetNotificationPreferences.html), [GetNotificationsUsage](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/GetNotificationsUsage.html), [SetNotificationPreferences](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/SetNotificationPreferences.html)

| ShoppingCartItemEndingSoon  | This notification is sent to a subscribed buyer when an item in the buyer's shopping cart is about to end. This event has a **TimeLeft** property that defines the 'ending soon' threshold value.   
  
This notification is deprecated, and will be decommissioned on January 11, 2027. After decommission, users can no longer subscribe to this event and instances of the notification event type will stop being sent to subscribers.  |  
| TokenRevocation  | This notification is applicable to both buyers and sellers and is sent if that user's authentication token is revoked.   
  
This notification will appear in the **GetTokenStatus** call response. See [TokenRevocation](https://developer.ebay.com/api-docs/static/pn_token-revocation.html) for additional information about this notification.  |  
| WatchedItemEndingSoon  | This buyer-facing notification is sent when a listing that the buyer is watching is ending soon. This event has a **TimeLeft** property that defines the 'ending soon' threshold value.   
  
This notification will appear in the **GetItem** call response. See [WatchedItemEndingSoon](https://developer.ebay.com/api-docs/static/pn_watched-item-ending-soon.html) for additional information about this notification.  |
