# Push notifications made easy
**ntfy** (pronounced _notify_) is a simple HTTP-based [pub-sub](https://en.wikipedia.org/wiki/Publish%E2%80%93subscribe_pattern) notification service. It allows you to send notifications to your phone or desktop via scripts from any computer, and/or using a REST API. It's infinitely flexible, and [100% free software](https://ntfy.sh/#free-software).

## Send push notifications from your app or script
[Publishing messages](https://ntfy.sh/docs/publish/) can be done via PUT or POST. Topics are created on the fly by subscribing or publishing to them. If you use ntfy without sign-up, the topic is essentially a password, so pick something that's not easily guessable. If you [purchase ntfy Pro](https://ntfy.sh/#pricing), you can reserve topic names instead.
curlntfy CLIJSGoPSPython

```
curl \
  -d "Backup successful 😀" \
  ntfy.sh/mytopic
```

## Or get notified on your computer
You can use the web app to subscribe to topics as well. If you do, notifications will pop up as desktop notifications. Simply type in the topic name and click the Subscribe button. The browser will keep a connection open and listen for incoming notifications.
