# Selling API Overview
This API allows partners to integrate directly with Depop to manage inventory and orders.
We've designed this RESTful API to be clear, easy to use, with versioning in mind for long-term durability.
New to Depop?
If you're considering integrating with us, our [Why Depop?](https://partnerapi.depop.com/api-docs/why-depop/) guide is the perfect place to start.
Learn about our mission, our impact on circular fashion, and why leading brands and sellers choose to grow their business with us.
## Features
  * **Authentication** : Secure access using simple API Keys.
  * **Inventory Management** : Create, update, and delete items in your inventory.
  * **Order Management** : Retrieve and manage orders placed by users. Webhooks are available for real-time updates.
  * **Offers Automation** : Automate the process of sending and responding to offers.
  * **Testing Environment** : A sandbox environment is available for testing your integration without affecting production data. This includes a mechanism to simulate purchases.


## Getting started
Warning
This API is currently private and is not available to the general public. If you are interested in integrating with Depop, please contact us at business@depop.com, and we'll get back to you with the next steps.
Head on over to [Your first listing](https://partnerapi.depop.com/api-docs/getting-started/your-first-listing/) guide to get started with creating your first listing using the API.
