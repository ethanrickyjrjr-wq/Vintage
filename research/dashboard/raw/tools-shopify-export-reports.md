# Exporting reports
You can export your reports to a different file format from your Shopify admin. Exported reports are saved in the default downloads folder on your device. After the download is complete, you can open the report using a spreadsheet program, such as Excel or Numbers, or a text editor.
You can export most reports in any of the following file formats:
  * Comma Separated Values (CSV)
  * Extensible Markup Language (XML)
  * JSON Lines (JSONL)
  * Apache Parquet (`.parquet`)


For some of the legacy Finances reports (Sales, Taxes, and Payments), the default file format is a CSV, but you can select the type of report to export:
  * **Current page** exports data for the columns that are currently displayed.
  * **Full report** exports data for all the displayed columns, but includes additional columns that aren't displayed by default.


If you want a PDF file of a report, then you can print the report instead of exporting.

## Export a report
You can export a report to your device. Exported report files are saved in your default downloads folder.
#### Steps:
Desktop
  1. From your Shopify admin, go to **Analytics** > [**Reports**](https://admin.shopify.com/analytics/reports).
  2. Click the report that you want to export.
  3. Click ![Horizontal menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuHorizontalIcon.svg) > **↥ Export**.
  4. If available, in the **Export report** dialog, select the file format that you want to use.
  5. Click **Export**.

Mobile
  1. From the [Shopify app](https://www.shopify.com/install/detect), tap the ![Menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuIcon.svg) icon.
  2. In the **Analytics** menu, tap the ![arrow down](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/ChevronDownIcon.svg) icon, and then tap **Reports**.
  3. Tap the report that you want to export.
  4. Tap ![Horizontal menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuHorizontalIcon.svg) or ![Vertical menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuVerticalIcon.svg) > **Export**.
  5. If available, in the **Export report** dialog, select the file format that you want to use.
  6. Tap **Export**.


## Print a report
To export a report to a PDF file, you can print the report instead of exporting it.
On a device that uses Windows 10 or higher, or on a Mac, you can automatically save to PDF when printing. For earlier versions of Windows, you need to install a PDF printer or converter, such as Adobe Acrobat Reader.
#### Steps:
Desktop
  1. From your Shopify admin, go to **Analytics** > [**Reports**](https://admin.shopify.com/analytics/reports).
  2. Click the report that you want to export.
  3. Click ![Horizontal menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuHorizontalIcon.svg) > **Print**.
  4. In the **Print** dialog, set your preferred printing settings.
  5. Click **Save** or **Print**.

Mobile
  1. From the [Shopify app](https://www.shopify.com/install/detect), tap the ![Menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuIcon.svg) icon.
  2. In the **Analytics** menu, tap the ![arrow down](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/ChevronDownIcon.svg) icon, and then tap **Reports**.
  3. Tap the report that you want to export.
  4. Tap ![Horizontal menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuHorizontalIcon.svg) or ![Vertical menu](https://cdn.shopify.com/shopifycloud/help-center/manual/admin-icons/MenuVerticalIcon.svg) > **Print**.
  5. In the **Print** dialog, set your preferred printing settings.
  6. Tap **Save** or **Print**.
