# Seller Hub Reports

The Reports tab in [Seller Hub - opens in new window or tab](https://www.ebay.co.uk/sh/reports) makes it easier to for high-volume sellers to manage their eBay business in bulk. 
Using templates, sellers can create and upload files to add, revise, relist, and end listings.
[Go to Seller Hub Reports - opens in new window or tab](https://ebay.co.uk/sh/reports)
## Seller Hub Reports features
Here are some of the many things you can do with Seller Hub Reports:
  * Create listings in bulk
  * Upload, download, and schedule reports
  * Fulfill orders
  * Mark items as dispatched
  * Find items that have been paid or posted
  * Manage feedback
  * Identify and fix errors in your listings in bulk


If you're a first time user of Reports, all you need to get started is an eBay account with access to Seller Hub. Business sellers are automatically opted in to Seller Hub. Private sellers just need to have made at least one sale to get access.
## Getting started
Whether you're listing inventory for the first time or editing existing listings, you should start by creating templates in the Upload section. Here's how:
How to create templates to bulk list your inventory on eBay
  1. Go to the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports) in Seller Hub.
  2. Select **Upload** on the left-hand side.
  3. Select the **Get template** button.
  4. Select **Listings** from the **Source** options.
  5. Select **Create new listings template** as the template **Type**.
  6. Select **Download**.


If Reports is new to you, we recommend that you try listing a single product first to familiarise yourself with the tool.
How to create templates to bulk edit and manage existing listings and orders
  1. Go to the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports) in Seller Hub.
  2. Select **Upload** on the left-hand side.
  3. Select the **Get template** button.
  4. Choose **Orders** or **Listings** from the **Source** options.
  5. Select the template **Type**. (e.g. Edit price, quantity or delete listings, Add order tracking and feedback).
  6. If you choose Orders as the template source, select the **Date Range** for the report (from 1-90 days). 
  7. Select **Download**.


Creating new listings through the reports tab generally requires image hosting. However, if you use the Create Drafts template, you can just leave the image URL column blank. Then add images later when you're converting draft to listings. 
How to create draft templates
  1. Go to the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports)in Seller Hub.
  2. Select **Upload** on the left-hand side.
  3. Select the **Get template** button.
  4. Select **Listings** from the Source options.
  5. Select **Create drafts template** as the template Type.
  6. Select **Download**.


**Tip**  
Templates and reports created or scheduled in the legacy File Exchange tool will not be carried over to the new Reports tool. To generate new templates and reports in Seller Hub, follow the instructions above.
## Uploading templates
Once you've added information to the template, the process for uploading it is the same whether you're listing new inventory or editing existing listings in bulk. Here's how to do it:
  1. Go back to the Upload section of the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports).
  2. Select the **Upload template** button.
  3. Choose .xlsx file type if you plan to use Excel, otherwise choose .csv file type.
  4. Select the template type you're uploading.
  5. Select **Upload**.


Once you hit **Upload** , your file will be processed and all the actions you requested will be run. This usually takes less than 15 minutes, though very large files can take longer. When the upload is finished, you'll see a message saying **Your upload is complete** and a downloadable report of all the actions taken will be generated.
## Downloading and scheduling reports
You can generate, download, and keep track of reports on your orders and listings from the Download section. Reports are very useful for a number of reasons, including record-keeping, auditing and order fulfillment. For example, you can create a scheduled order fulfillment report to automatically update postage details at a frequency that suits you, saving you a lot of manual work.
Hit the **+** icon to see how to generate and download a new report.
How to download reports
  1. Go to the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports) in Seller Hub.
  2. Select **Download** on the left-hand side.
  3. Select the **Download report** button.
  4. Choose **Orders** or **Listings** from the **Source** options.
  5. Select the **Type** of report you want to schedule (e.g. All orders, Awaiting Postage, etc.).
  6. Select the **Date Range** for the report (from 1-90 days).
  7. Select **Download**.


**To download a previously existing report:**
  1. Find the report you want to download in the "Recent downloads" section.
  2. Select **Download**.


You can also set up and manage recurring automatic reports about your orders from the Schedule section. Hit the + icon to see how
How to schedule automated reports
  1. Go to the [Reports tab - opens in new window or tab](https://ebay.co.uk/sh/reports) in Seller Hub.
  2. Select **Schedule** on the left-hand side.
  3. Select the **Create download schedule** button.
  4. Choose **Orders** from the **Source** options.
  5. Select the **Type** of report you want to schedule (e.g. All orders, Awaiting Postage, etc.).
  6. Select the **Frequency** of your reports (Hourly, Daily, Weekly or Monthly).
  7. Select a **Run Time**.
  8. Select an **Ends on date** of the report or select **No end date**.
  9. Select **Save**.


**Updating existing scheduled reports:**
  1. Find the report you want to edit in the "Scheduled reports" section.
  2. Select **Modify** then **Edit** (or **Delete** if you want to remove it completely).
  3. Make your edits then select **Save**.


## Merchant Integration Platform
Sellers who have a stock-keeping unit (SKU) or custom label-based inventory may prefer to use eBay's Merchant Integration Platform – another bulk management tool for high-volume sellers.
The service makes it easy to turn your inventory into eBay listings. Just upload a CSV or XML file to list your products, manage your eBay inventory, and fulfil orders.
Managing your inventory with SKUs can make it even easier to sell across eBay's international marketplaces. MIP can upload over 50,000 SKUs in under 30 minutes.
To subscribe, go to the [Merchant Integration Platform page - opens in new window or tab](https://www.mip.ebay.co.uk/nglanding) and select **Get started**.
