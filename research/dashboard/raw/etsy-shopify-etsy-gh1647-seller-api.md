[![](https://avatars.githubusercontent.com/in/1062435?s=64&v=4) openapi-support[bot] ](https://github.com/apps/openapi-support) Bot [ Jul 13, 2026 ](https://github.com/etsy/open-api/discussions/1647#discussion-10422129)  
|  We're launching **Seller API Access** today — a new tier that lets individual sellers build tools and services for their own shop. It replaces the Personal Key tier as the path for sellers, with a faster application and review process. **How it works**
  * **Clear eligibility:** any seller with an active Etsy shop in good standing who doesn't already have a registered app.
  * **Automated approval:** eligible sellers are approved within minutes, with no manual review queue
  * **Simplified form:** two required fields instead of the previous multi-step application form
  * **Scoped access:** read and write access to your own shop's data via OAuth (details [here](https://developer.etsy.com/documentation/essentials/authentication))

**What's not in scope** Sellers who already hold an existing personal key are not eligible for this tier, as their current keys provide comparable access. Furthermore, this tier is not intended for building commercial applications for other sellers; the path for commercial access remains unchanged for that specific use case. **What this means for you** New sellers requesting access: apply for Seller API Access [here](https://www.etsy.com/developers). Personal Key is still a prerequisite for Commercial Access — that path is unchanged Questions? Check out our [developer documentation](https://developer.etsy.com/documentation/) or reach out to developer@etsy.com.  |
