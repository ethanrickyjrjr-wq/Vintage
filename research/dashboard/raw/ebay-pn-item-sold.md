This notification is sent to the subscribed seller when an eBay listing ends in a sale, and the listing had at least one sale while it was active.
## Data Fields Returned
**API Call that displays this notification:** [GetItem](https://developer.ebay.com/Devzone/XML/docs/Reference/eBay/GetItem.html)
The data fields returned by the **ItemSold** notification are the same as those returned by **GetItemResponse**. Refer to the [GetItem](https://developer.ebay.com/devzone/XML/docs/Reference/eBay/GetItem.html#GetItem) call reference documentation for additional information.
Refer to [SOAP Message Body](https://developer.ebay.com/api-docs/static/platform-notifications-landing.html#soap-body) for information about the standard elements returned for all notifications.
