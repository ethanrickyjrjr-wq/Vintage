# Triggers in Shopify Flow
Triggers are events that start a workflow. After you select a trigger to start a workflow, you can set [actions](https://help.shopify.com/en/manual/shopify-flow/reference/actions) to take place immediately or you can set [conditions](https://help.shopify.com/en/manual/shopify-flow/reference/conditions) to determine what actions are performed. Learn more about [understanding the basics of triggers](https://help.shopify.com/en/manual/shopify-flow/getting-started/understanding-triggers).
