# Developer Technical Support
Formal eBay support is provided by the Developer Technical Support team. To interact with [Developer Technical Support](https://developer.ebay.com/my/support/tickets), you must be a registered eBay developer.
To utilize the benefits of technical support, you must first activate support for your developer account. Activating support allows you to interact with the eBay Developer Technical Support team. To activate support:
  1. Log into your Developer account and go to your [Profile & Contacts](https://developer.ebay.com/my/profile) page.
  2. From the Primary Contact section, ensure your name, email, phone, and country are filled out. If not, click **Edit** , complete these fields, and click **Save**.
  3. Click **Edit**.
  4. Click **Activate Support**.


Once you have activated support on your developer account, use the **AI-Assisted Support** tab to ask your question. If further assistance is needed, you can create a ticket from there.
## Contacting Developer Technical Support
Developer Technical Support is a premium developer service provided by eBay. The goal of the Developer Technical Support team is to make sure that you use the eBay APIs in the best fashion possible. While they cannot write your code for you, they can help you understand the best and most efficient way to use the eBay APIs.
To optimize the time you spend conversing with Developer Technical Support, they require that you prepare the information needed to isolate the issue(s) you've encountered.
At a minimum, prepare the following information before contacting Developer Technical Support:
  * The application ID of the application you're troubleshooting
  * A list of the eBay API calls you're using
  * Your error log(s)
  * The HTTP response header values
  * Any error messages returned by eBay


## Create a support request
Use Al-Assisted Support tab on the [Developer Technical Support](https://developer.ebay.com/my/support/tickets) page to create tickets.
Tip: When you encounter problems with a request, it's important that you save the HTTP response header values to help the support team find the details of the specific call with which you are having trouble.
