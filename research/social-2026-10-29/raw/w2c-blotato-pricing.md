PRICING FAQ
##  Common _questions_ . 
01 Is Blotato free?
There's no free plan, but every plan includes a 7-day free trial. A card is required, nothing is charged during the trial, and you can cancel anytime before it ends. The trial includes every web app feature plus 60 AI credits, but not the API or MCP: generating an API key ends the trial and starts your paid plan. When the trial ends, your card is charged for the plan you picked. Starter is $29/month for 20 social media accounts, with no per-post fees, though account and scheduled-post limits apply.
02 What happens after my free trial?
Your trial runs for 7 days. We'll email you before it ends. If you cancel before then, you're not charged. If you stay, your card is charged for the plan you signed up for. You can downgrade or cancel any time after that, no clawback, no calls.
03 Does the free trial include the API and MCP?
No. The trial covers the web app, but not the API or the MCP server. Generating an API key in Settings > API ends the trial right away and starts your paid subscription, even with trial days left. n8n and Make also need an API key. If you're connecting an AI agent or an automation, plan on starting a paid plan. Every paid plan includes the API and MCP, with no separate API tier.
04 What's an AI credit?
Credits power AI image and video generation. Writing is unlimited on every plan, and scheduling, publishing, AI voiceovers and API calls themselves don't use credits. Each credit roughly maps to a generated image or a few seconds of generated video. Most operators on Creator never hit the 5,000-credit cap.
05 Can I switch plans?
Yes. Upgrade or downgrade any time inside the app. Upgrades pro-rate immediately. Downgrades take effect at the next billing cycle.
06 Do you offer annual pricing?
Yes. Yearly billing saves about 17%: you pay for 10 months and get 12. This page sells monthly plans, so switch to yearly with Update subscription in the Billing Portal, under Settings > Billing. You don't need to cancel your monthly plan first.
07 Is there a Blotato promo code?
Only while a limited-time promotion is running. The Current Promo page in the Blotato help center shows whether one is live right now, so check it before using a code from a coupon site. A code goes in the discount field at checkout when you first subscribe. For a plan you're already paying for, ask support in the in-app chat whether the code can apply.
08 Is there a refund policy?
If something genuinely doesn't work, email support@blotato.com within 14 days and we'll make it right. The free trial is the better way to make sure it fits before you commit.
09 How is Blotato different from other tools?
Blotato is the only platform that combines proven viral templates, an AI writer fine-tuned on viral posts, native cross-posting, faceless video, an AI coach, and an API + MCP - built and used by an operator who actually grew the audience (3M+ followers, 500M+ views). Most tools cover one slice. We cover the stack.
