# FFmpeg Static Builds
Welcome! Here you'll find the latest versions of [FFmpeg](http://ffmpeg.org/) for Linux kernels 3.2.0 and up. For installation instructions please read the [FAQ.](https://www.johnvansickle.com/ffmpeg/faq/)
**Note:** it's highly recommended to use git master builds, because bug fixes and other improvements are added daily.
