Limits
Limits applied Edge Functions in Supabase's hosted platform.
## Runtime limits[#](https://supabase.com/docs/guides/functions/limits#runtime-limits)
  * Maximum Memory: 256MB
  * [Maximum Duration (Wall clock limit)](https://supabase.com/kb/troubleshooting/edge-function-wall-clock-time-limit-reached-Nk38bW): This is the duration an Edge Function worker will stay active. During this period, a worker can serve multiple requests or process [background tasks](https://supabase.com/docs/guides/functions/background-tasks).
    * Free plan: 150s
    * Paid plans: 400s
  * [Maximum CPU Time](https://supabase.com/kb/troubleshooting/edge-function-cpu-limits): 2s (Amount of actual time spent on the CPU per request - does not include async I/O.)
  * Request idle timeout: 150s (If an Edge Function doesn't send a response before the timeout, 504 Gateway Timeout will be returned)


## Platform limits[#](https://supabase.com/docs/guides/functions/limits#platform-limits)
  * [Maximum Function Size](https://supabase.com/kb/troubleshooting/edge-function-bundle-size-issues): 20MB (bundled locally via the CLI) or 5MB (bundled server-side, e.g. via the Management API or Dashboard)
  * Maximum no. of Functions per project:
    * Free: 100
    * Pro: 1000
    * Team: 2000
    * Enterprise: Unlimited
  * Maximum log message length: 10,000 characters
  * Log event threshold: 100 events per 10 seconds
  * Recursive/Nested Function Calling: 30 requests per trace, within a 60-second window [more details](https://supabase.com/docs/guides/functions/recursive-functions)


### Secrets[#](https://supabase.com/docs/guides/functions/limits#secrets)
  * Maximum number of secrets per project: **100**
  * Secret name length: up to **256** characters
  * Maximum secret size: **48 KiB** (**24,576** characters)
  * Names must NOT start with the prefix `SUPABASE_` (this prefix is reserved).
  * Need more than 100 secrets? [Bundle secrets into a JSON value](https://supabase.com/kb/troubleshooting/working-around-the-edge-function-secrets-limit).


## Other limits & restrictions[#](https://supabase.com/docs/guides/functions/limits#other-limits--restrictions)
  * Outgoing connections to ports `25` and `587` are not allowed.
  * Serving of HTML content is only supported with [custom domains](https://supabase.com/docs/reference/cli/supabase-domains) (Otherwise `GET` requests that return `text/html` will be rewritten to `text/plain`).
  * Web Worker API (or Node `vm` API) are not available.
  * Static files cannot be deployed using the API flag. You need to build them with [Docker on the CLI](https://supabase.com/docs/guides/functions/quickstart#step-6-deploy-to-production).
  * Node Libraries that require multithreading are not supported. Examples: [`libvips`](https://github.com/libvips/libvips), [sharp](https://github.com/lovell/sharp).
