# Descript API
## Automate 90% while you do other stuff
Set up a trigger. Tell Underlord what to do. Show up when the work is ready.
[Contact sales](https://www.descript.com/contact)[See how](https://www.descript.com/api#get-started)
Need auth, endpoints, and examples? [The API docs](https://help.descript.com/developers) have all of it.
How it works
## Triggers in. Edited video out.
You define what kicks things off, and Underlord takes it from there. You show up when it's time to review.
![1. Something happens](https://cdn.sanity.io/images/lsw4j9eq/production/400755c56e021300e074bb02f8dc44e9a888b359-992x600.png?fit=max&auto=format)
### 1. Something happens
A new recording. A published article. A file upload. You pick the trigger.
![2. Underlord does the work](https://cdn.sanity.io/images/lsw4j9eq/production/ecaa4cda35fc462fe329abd213d565d6a4a112b7-992x600.png?fit=max&auto=format)
### 2. Underlord does the work
Import, transcribe, remove filler words, add Studio Sound, cut clips, generate captions — whatever you've told it to do.
![3. You show up for the last 10%](https://cdn.sanity.io/images/lsw4j9eq/production/430387b4b360f209e762fd17d90f010b03c622c7-992x600.png?fit=max&auto=format)
### 3. You show up for the last 10%
Open Descript, review the rough cut, make it great. The boring part is already done.

## Four ways in. No developer required.
![Claude / MCP](https://cdn.sanity.io/images/lsw4j9eq/production/b0c0d63633bfbed77ac36cfd52bedf65f0f42d9f-1050x450.jpg?fit=max&auto=format)
### Claude / MCP
Use the API through a conversation. Connect the Descript MCP to Claude (or another AI assistant), and you can trigger imports and edits just by asking. Describe what you want in plain English — the model figures out the API calls for you.
[Connect with MCP](https://web.descript.com/view/settings/account?active=mcp)
![Zapier](https://cdn.sanity.io/images/lsw4j9eq/production/182d7a8f925c61341910888f50a97987e342c183-1050x450.jpg?fit=max&auto=format)
### Zapier
Connect Descript to your existing workflows - without code. Connect Descript, set your trigger (new file, new recording, new post), and tell Underlord what to do. Great for no-code automation.
[Connect Descript on Zapier](https://help.descript.com/hc/en-us/articles/43370311322509-Descript-API)
![Command Line](https://cdn.sanity.io/images/lsw4j9eq/production/8f8ac23a67eda659e77dfa608a1c47f5138de5d5-1050x450.jpg?fit=max&auto=format)
### Command Line
For poking around quickly. Install the CLI, drop in your API key, and run imports and edits from your terminal. It handles the polling and shows live progress — useful for quickly testing before you build something real.
[Get started with the CLI](https://docs.descriptapi.com/#tag/Using-the-CLI)
![Direct API](https://cdn.sanity.io/images/lsw4j9eq/production/91ee08aad95de52c4caebfcb5cd8e381a6e6b7fa-1050x450.jpg?fit=max&auto=format)
### Direct API
Full control, for production workflows. Call the API directly over HTTP when you're ready to build something real. You own the logic — job orchestration, error handling, webhooks, the whole thing.
[Read the API documentation](https://help.descript.com/developers)

## Frequently asked questions
  * ### Do I need to be a developer to use this?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
No. If you can use Zapier or connect an app to Claude, you can set this up. The CLI and direct API are there for technical users, but they're not required.
  * ### What can I automate?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
Import media from URL or local upload, apply any edits Underlord can do, and publish you project via share page or generate a download URL. Remove filled words, add Studio sound, generate captions, create clips, translate and dub, build rough cuts, and much more. If you can prompt it with Underlord in Descript, you can automate it through the API.
  * ### What's a good first workflow to try?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
Start simple: trigger on a new recording landing in a target folder, have Underlord remove filler words and add captions, review in Descript. Once that's working, build from there.
  * ### What does it cost?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
API access is available for all paying users at no additional cost. Usage draws from the AI credits and media minutes on your plan.
  * ### How do I get my API token?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
In Descript: [Settings → API Tokens](https://web.descript.com/view/settings/account?active=api). Tokens are scoped to a specific Drive.
  * ### What triggers can I use?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
Anything you can wire up in Zapier or through your own integration: RSS feeds, file uploads, CRM events, calendar events, webhooks from your recording platform — whatever fits your workflow.
  * ### Do I have to review everything, or can I auto-publish?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
You can auto-publish! Publishing a project composition creates a shareable link and generates a URL to download the exported file.
  * ### What should I know before I build on the API?
![](https://static-cdn.descript.com/descript-website/images/chevron-down-light.svg)
You can export transcripts and timelines directly via the API, and publish your projects to generate web links, but direct media file exports are not supported yet. You'll need to do this manually in Descript for now. For more, visit the [known limitations page](https://descript.notion.site/descript-apis-known-issues) or consult the [API docs](https://docs.descriptapi.com/openapi-experimental.html) for an endpoint by endpoint breakdown.
