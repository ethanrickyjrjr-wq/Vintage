# renderStill()[v2.3](https://github.com/remotion-dev/remotion/releases/v2.3)
_Part of the`@remotion/renderer` package._
Renders a single frame to an image and writes it to the specified output location.
If you want to render a video, use [`renderMedia()`](https://www.remotion.dev/docs/renderer/render-media) instead.
## Example usage[​](https://www.remotion.dev/docs/renderer/render-still#example-usage "Direct link to Example usage")
You first need to bundle the project and fetch the compositions.  
Read [the code snippet on the site for server-side rendering](https://www.remotion.dev/docs/ssr) for an example how to come up with the `serveUrl` and `composition` variables.

```
await renderStill({
  composition,
  serveUrl,
  output: '/tmp/still.png',
  inputProps: {
    custom: 'data',
  },
});Copy
```

## Arguments[​](https://www.remotion.dev/docs/renderer/render-still#arguments "Direct link to Arguments")
Takes an object with the following properties:
###  `composition`[​](https://www.remotion.dev/docs/renderer/render-still#composition "Direct link to composition")
_VideoConfig_
An object describing a composition using `id`, `width`, `height`, `fps` and `durationInFrames`, `defaultProps` and `props`. Call [`selectComposition()`](https://www.remotion.dev/docs/renderer/select-composition) or [`getCompositions()`](https://www.remotion.dev/docs/renderer/get-compositions) to get an array of possible configs.
###  `serveUrl`[​](https://www.remotion.dev/docs/renderer/render-still#serveurl "Direct link to serveurl")
_string_
Either a local path pointing to a Remotion Webpack bundle generated by [`bundle()`](https://www.remotion.dev/docs/bundle) or a URL where the bundle is hosted.
###  `output`[​](https://www.remotion.dev/docs/renderer/render-still#output "Direct link to output")
_string_
An absolute path to where the frame should be rendered to.
###  `inputProps?`[​](https://www.remotion.dev/docs/renderer/render-still#inputprops "Direct link to inputprops")
_object_
[Input Props to pass to the selected composition of your video.](https://www.remotion.dev/docs/passing-props#passing-input-props-in-the-cli). Must be a JSON object. From the root component the props can be read using [`getInputProps()`](https://www.remotion.dev/docs/get-input-props). You may transform input props using [`calculateMetadata()`](https://www.remotion.dev/docs/calculate-metadata).
###  `port?`[​](https://www.remotion.dev/docs/renderer/render-still#port "Direct link to port")
_number_
Prefer a specific port that will be used to serve the Remotion project. If not specified, a random port will be used.
###  `frame?`[​](https://www.remotion.dev/docs/renderer/render-still#frame "Direct link to frame")
Which frame should be rendered based on its number. Default: `0`. Frames are zero-indexed.
From v3.2.27, negative values are allowed, with `-1` being the last frame.
To render multiple stills in one call, use [`renderFrames()` with the `frames` option](https://www.remotion.dev/docs/renderer/render-frames#frames). For example, `frames: [0, 30, 90]` renders those three frames.[v4.0.502](https://github.com/remotion-dev/remotion/releases/v4.0.502)
###  `imageFormat?`[​](https://www.remotion.dev/docs/renderer/render-still#imageformat "Direct link to imageformat")
_string_ [`StillImageFormat`](https://www.remotion.dev/docs/renderer/types#stillimageformat "You can import the TypeScript type `StillImageFormat` from @remotion/renderer")
Which output format the image should have, either `png`, `jpeg`, `webp` or `pdf`. Default: `"png"`.
###  `scale?`[​](https://www.remotion.dev/docs/renderer/render-still#scale "Direct link to scale")
Scales the output dimensions by a factor. For example, a 1280x720px frame will become a 1920x1080px frame with a scale factor of `1.5`. See [Scaling](https://www.remotion.dev/docs/scaling) for more details.
###  `jpegQuality?`[​](https://www.remotion.dev/docs/renderer/render-still#jpegquality "Direct link to jpegquality")
Sets the JPEG quality - must be an integer between 0 and 100 and can only be passed if `imageFormat` is set to `jpeg`.
###  `puppeteerInstance?`[​](https://www.remotion.dev/docs/renderer/render-still#puppeteerinstance "Direct link to puppeteerinstance")
An already open [`Browser`](https://www.remotion.dev/docs/renderer/open-browser) instance. Use [`openBrowser()`](https://www.remotion.dev/docs/renderer/open-browser) to create a new instance. Reusing a browser across multiple function calls can speed up the rendering process. You are responsible for opening and closing the browser yourself. If you don't specify this option, a new browser will be opened and closed at the end.
note
Despite the name, not actually compatible with `puppeteer`, only with [`openBrowser()`](https://www.remotion.dev/docs/renderer/open-browser).
###  `envVariables?`[​](https://www.remotion.dev/docs/renderer/render-still#envvariables "Direct link to envvariables")
An object containing key-value pairs of environment variables which will be injected into your Remotion project and which can be accessed by reading the global `process.env` object. Default: `{}`.
###  `logLevel?`[v4.0.115](https://github.com/remotion-dev/remotion/releases/v4.0.115)[​](https://www.remotion.dev/docs/renderer/render-still#loglevel "Direct link to loglevel")
One of `trace`, `verbose`, `info`, `warn`, `error`.  
Determines how much info is being logged to the console.  
  
Default `info`.
###  `onArtifact?`[v4.0.176](https://github.com/remotion-dev/remotion/releases/v4.0.176)[​](https://www.remotion.dev/docs/renderer/render-still#onartifact "Direct link to onartifact")
_function_ [`OnArtifact`](https://www.remotion.dev/docs/renderer/types#onartifact "You can import the TypeScript type `OnArtifact` from @remotion/renderer")
[Handle an artifact](https://www.remotion.dev/docs/artifacts#using-rendermedia-renderstill-or-renderframes) that was emitted by the [`<Artifact>`](https://www.remotion.dev/docs/artifact) component.
###  `overwrite?`[​](https://www.remotion.dev/docs/renderer/render-still#overwrite "Direct link to overwrite")
Whether the file should be overwritten if the output already exists. Default: `true`.
###  `browserExecutable?`[v2.3.1](https://github.com/remotion-dev/remotion/releases/v2.3.1)[​](https://www.remotion.dev/docs/renderer/render-still#browserexecutable "Direct link to browserexecutable")
A string defining the absolute path on disk of the browser executable that should be used. By default Remotion will try to detect it automatically and download one if none is available.
###  `onBrowserLog?`[v3.3.93](https://github.com/remotion-dev/remotion/releases/v3.3.93)[​](https://www.remotion.dev/docs/renderer/render-still#onbrowserlog "Direct link to onbrowserlog")
_function_ [`BrowserLog`](https://www.remotion.dev/docs/renderer/types#browserlog "You can import the TypeScript type `BrowserLog` from @remotion/renderer")
Gets called when your project calls `console.log` or another method from console. See the documentation for [`renderFrames`](https://www.remotion.dev/docs/renderer/render-frames#onbrowserlog) for more information.
###  `timeoutInMilliseconds?`[v2.6.3](https://github.com/remotion-dev/remotion/releases/v2.6.3)[​](https://www.remotion.dev/docs/renderer/render-still#timeoutinmilliseconds "Direct link to timeoutinmilliseconds")
A number describing how long the render may take to resolve all [`delayRender()`](https://www.remotion.dev/docs/delay-render) calls [before it times out](https://www.remotion.dev/docs/timeout). Default: `30000`
###  `cancelSignal?`[v3.0.15](https://github.com/remotion-dev/remotion/releases/v3.0.15)[​](https://www.remotion.dev/docs/renderer/render-still#cancelsignal "Direct link to cancelsignal")
A token that allows the render to be cancelled. See: [`makeCancelSignal()`](https://www.remotion.dev/docs/renderer/make-cancel-signal)
###  `chromiumOptions?`[v2.6.5](https://github.com/remotion-dev/remotion/releases/v2.6.5)[​](https://www.remotion.dev/docs/renderer/render-still#chromiumoptions "Direct link to chromiumoptions")
Allows you to set certain Chromium / Google Chrome flags. See: [Chromium flags](https://www.remotion.dev/docs/chromium-flags).
note
Chromium flags need to be set at browser launch. If you pass an instance using [`puppeteerInstance`](https://www.remotion.dev/docs/renderer/render-still#puppeteerinstance), options passed to `renderStill()` will not apply, but rather the flags that have been passed to [`openBrowser()`](https://www.remotion.dev/docs/renderer/open-browser).
####  `disableWebSecurity`[​](https://www.remotion.dev/docs/renderer/render-still#disablewebsecurity "Direct link to disablewebsecurity")
_boolean - default`false`_
This will most notably disable CORS among other security features.
####  `enableMultiProcessOnLinux?`[v4.0.42](https://github.com/remotion-dev/remotion/releases/v4.0.42)[​](https://www.remotion.dev/docs/renderer/render-still#enablemultiprocessonlinux "Direct link to enablemultiprocessonlinux")
Removes the `--single-process` flag that gets passed to Chromium on Linux by default. This will make the render faster because multiple processes can be used, but may cause issues with some Linux distributions or if window server libraries are missing.  
Default: `false` until v4.0.136, then `true` from v4.0.137 on because newer Chrome versions don't allow rendering with the `--single-process` flag.   
This flag will be removed in Remotion v5.0.
####  `ignoreCertificateErrors?`[​](https://www.remotion.dev/docs/renderer/render-still#ignorecertificateerrors "Direct link to ignorecertificateerrors")
_boolean - default`false`_
Results in invalid SSL certificates, such as self-signed ones, being ignored.
####  `headless?`[​](https://www.remotion.dev/docs/renderer/render-still#headless "Direct link to headless")
If disabled, the render will open an actual Chrome window where you can see the render happen. This requires [Chrome for Testing](https://www.remotion.dev/docs/miscellaneous/chrome-headless-shell) or a custom Chrome or Chromium executable. Chrome Headless Shell always runs headlessly. The default is headless mode.
####  `gl`[​](https://www.remotion.dev/docs/renderer/render-still#gl "Direct link to gl")
Changelog
  * From Remotion v2.6.7 until v3.0.7, the default for Remotion Lambda was `swiftshader`, but from v3.0.8 the default is `swangle` (Swiftshader on Angle) since Chrome 101 added support for it.
  * From Remotion v2.4.3 until v2.6.6, the default was `angle`, however it turns out to have a small memory leak that could crash long Remotion renders.


Select the OpenGL renderer backend for Chromium.   
Accepted values:
  * `"angle"`
  * `"egl"`
  * `"swiftshader"`
  * `"swangle"`
  * `"vulkan"` (_from Remotion v4.0.41_)
  * `"angle-egl"` (_from Remotion v4.0.51_)


The default is `null`, letting Chrome decide, except on Lambda where the default is `"swangle"`
####  `userAgent`[v3.3.83](https://github.com/remotion-dev/remotion/releases/v3.3.83)[​](https://www.remotion.dev/docs/renderer/render-still#useragent "Direct link to useragent")
Lets you set a custom user agent that the headless Chrome browser assumes.
####  `darkMode?`[v4.0.381](https://github.com/remotion-dev/remotion/releases/v4.0.381)[​](https://www.remotion.dev/docs/renderer/render-still#darkmode "Direct link to darkmode")
Whether Chromium should pretend to be in dark mode by emulating the media feature 'prefers-color-scheme: dark'. Default is `false`.
###  `mediaCacheSizeInBytes?`[v4.0.352](https://github.com/remotion-dev/remotion/releases/v4.0.352)[​](https://www.remotion.dev/docs/renderer/render-still#mediacachesizeinbytes "Direct link to mediacachesizeinbytes")
Specify the memory budget for decoded media cached by `<Video>` and `<Audio>` from `@remotion/media`, in bytes. This value also determines the maximum read cache size for each distinct media source. It is not a limit on total memory usage.   
The default is half of the available system memory when the render starts.
###  `preferredEffectBackend?`[v4.0.540](https://github.com/remotion-dev/remotion/releases/v4.0.540)[​](https://www.remotion.dev/docs/renderer/render-still#preferredeffectbackend "Direct link to preferredeffectbackend")
Prefer `webgpu`, `webgl2`, or `2d` implementations of [effects](https://www.remotion.dev/docs/effects). Default: `auto`, which tries WebGPU, WebGL2, then 2D. Falls back when an implementation or backend is unavailable. Lambda selects WebGL2 or 2D implementations. Rendering fails if an effect has no supported implementation. This option also applies to Studio preview.
###  `offthreadVideoCacheSizeInBytes?`[v4.0.23](https://github.com/remotion-dev/remotion/releases/v4.0.23)[​](https://www.remotion.dev/docs/renderer/render-still#offthreadvideocachesizeinbytes "Direct link to offthreadvideocachesizeinbytes")
From v4.0, Remotion has a cache for [`<OffthreadVideo>`](https://remotion.dev/docs/offthreadvideo) frames. The default is `null`, corresponding to half of the system memory available when the render starts.  
This option allows to override the size of the cache. The higher it is, the faster the render will be, but the more memory will be used.  
The used value will be printed when running in verbose mode.  
Default: `null`
###  `offthreadVideoThreads?`[v4.0.261](https://github.com/remotion-dev/remotion/releases/v4.0.261)[​](https://www.remotion.dev/docs/renderer/render-still#offthreadvideothreads "Direct link to offthreadvideothreads")
The number of threads that[`<OffthreadVideo>`](https://remotion.dev/docs/offthreadvideo) can start to extract frames. The default is 2. Increase carefully, as too many threads may cause instability.
###  `binariesDirectory?`[v4.0.120](https://github.com/remotion-dev/remotion/releases/v4.0.120)[​](https://www.remotion.dev/docs/renderer/render-still#binariesdirectory "Direct link to binariesdirectory")
The directory where the platform-specific binaries and libraries that Remotion needs are located. Those include an `ffmpeg` and `ffprobe` binary, a Rust binary for various tasks, and various shared libraries. If the value is set to `null`, which is the default, then the path of a platform-specific package located at `node_modules/@remotion/compositor-*` is selected.  
This option is useful in environments where Remotion is not officially supported to run like bundled serverless functions or Electron.
###  `onBrowserDownload?`[v4.0.137](https://github.com/remotion-dev/remotion/releases/v4.0.137)[​](https://www.remotion.dev/docs/renderer/render-still#onbrowserdownload "Direct link to onbrowserdownload")
Gets called when no compatible local browser is detected on the system and this API needs to download a browser. Return a callback to observe progress. [See here for how to use this option.](https://www.remotion.dev/docs/renderer/ensure-browser#onbrowserdownload)
###  `chromeMode?`[v4.0.248](https://github.com/remotion-dev/remotion/releases/v4.0.248)[​](https://www.remotion.dev/docs/renderer/render-still#chromemode "Direct link to chromemode")
One of `headless-shell, ``chrome-for-testing`. Default `headless-shell`. [Use `chrome-for-testing` to take advantage of GPU drivers on Linux.](https://remotion.dev/docs/miscellaneous/chrome-headless-shell)
###  `licenseKey?`[v4.0.409](https://github.com/remotion-dev/remotion/releases/v4.0.409)[​](https://www.remotion.dev/docs/renderer/render-still#licensekey "Direct link to licensekey")
License key for sending a usage event using `@remotion/licensing`. For `npx remotion render` and `npx remotion still`, pass a private API key starting with `rm_sec_` from the License keys page on [remotion.pro](https://www.remotion.pro/dashboard).
###  `isProduction?`[v4.0.409](https://github.com/remotion-dev/remotion/releases/v4.0.409)[​](https://www.remotion.dev/docs/renderer/render-still#isproduction "Direct link to isproduction")
_default`true`_
Pass `false` for a development render so it is not counted as a billable render on remotion.pro. Defaults to `true`. Only has an effect when a license key is provided.

## Return Value[​](https://www.remotion.dev/docs/renderer/render-still#return-value "Direct link to Return Value")
The return value is a promise that resolves to an object with the following keys:
  * `buffer`: [v3.3.9](https://github.com/remotion-dev/remotion/releases/v3.3.9) A `Buffer` that only exists if no `output` option was provided. Otherwise null.
  * `contentType`: [v4.0.426](https://github.com/remotion-dev/remotion/releases/v4.0.426) The content type of the rendered output, e.g. `"image/png"`, `"image/jpeg"`.
