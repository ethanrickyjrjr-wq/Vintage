##  [](/help "Back to help") Pickup - Can items be picked up from the selling Goodwill location? 
In general, most sellers allow items to be picked up from their location however please carefully review the Item Info tab as well as the Shipping tab on the main listing page for seller specific pickup information and/or restrictions.
  

To create a Pickup order and obtain Pickup hours and location information:
**> Visit your Open Orders page located under the MY SHOPGOODWILL tab**
**> Click the "$ Pay" button beside the item you would like to make payment for **
**> Select "In-Store Pickup" as the shipping option for the item and check the box confirming you are agreeing to pick up the item**
**> Select Proceed to Payment to finalize the order **
  

Please note that handling fees will still be applied.
  

For further information regarding Pickup of an item, please contact the seller directly by using the "Contact Seller" link on the main item listing page.
