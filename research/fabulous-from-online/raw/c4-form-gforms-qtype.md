# Choose a type of question for your form
You can select types of questions from a menu:
  1. Open a form in [Google Forms](https://forms.google.com/).
  2. On the right, click Add ![](https://storage.googleapis.com/support-kms-prod/c4YOnv5a1hKyv3ENYrgLk5cTTSQHOXu8Pzgh).
  3. To the right of the question title, choose the type of question you want.
  4. (Optional) To make it required for users to answer your question, turn **Required** on or off.
  5. (Optional) To add the “Description” field, click More ![](https://storage.googleapis.com/support-kms-prod/og5HHfAGvY6IERh0tFkgoGRBhHTxgavp1qzG) ![and then](https://lh3.googleusercontent.com/3_l97rr0GvhSP2XV5OoCkV2ZDTIisAOczrSdzNCBxhIKWrjXjHucxNwocghoUa39gw=h36) **Description**.
  6. (Optional) To find more options for each question, click More ![](https://storage.googleapis.com/support-kms-prod/og5HHfAGvY6IERh0tFkgoGRBhHTxgavp1qzG).


## Types of questions
Short answer
  * You can provide an open question. Responders can find one line to write their answer in a few words.
  * You can set rules such as maximum character count. [Learn how to set rules with data validation](https://support.google.com/docs/answer/3378864#short_answer).


Paragraph
  * You can provide an open question. Responders can write long answers in paragraphs.
  * You can set rules such as maximum or minimum character count. [Learn how to set rules with data validation](https://support.google.com/docs/answer/3378864#short_answer).


Multiple choice
  * You can provide a set of options. Responders can choose only one option.
  * You can include "Other" as an option. Responders can type a short answer.


  * Based on a responder’s answers, you can send them to a certain section of the form. [Learn how to show questions based on answers](https://support.google.com/docs/answer/141062).


Checkboxes
  * You can provide a set of options. Responders can select multiple answers.
  * You can include "Other" as an option. Responders can type a short answer.


  * Based on a responder’s answers, you can send them to a certain section of the form. [Learn how to show questions based on answers](https://support.google.com/docs/answer/141062).


Dropdown
  * You can provide a set of options. Responders can choose only one option.


  * Based on a responder’s answers, you can send them to a certain section of the form. [Learn how to show questions based on answers](https://support.google.com/docs/answer/141062).


File upload
You can ask the responder to upload a file in your form.
**Important:**
  * You can’t use this question type, if: 
    * The form is stored in [a shared drive](https://support.google.com/drive/answer/7286514?co=GENIE.Platform%3DDesktop&hl=en&oco=0).
    * Your administrator turns on [Data Loss Prevention](https://support.google.com/a/answer/6321530).
  * To answer this question, responders need to sign in to a Google Account.
  * For the form owner, uploaded files are stored in a new folder on Google Drive.


To set up a file upload question, you can:
  * Specify which file types responders can upload.
  * Set up the maximum number of files responders can upload.
  * Choose the maximum file size responders can upload.


Linear scale
You can ask responders to provide a rating on a scale.
  * Your scale can start at zero or one.
  * Your scale can end on a whole number from 2 to 10.
  * You can set a label for each end of the scale.


Rating
You can ask responders to provide a rating.
  * You can represent your rating with a: 
    * Star
    * Heart
    * Thumbs up
  * Your rating can be a whole number from 3 to 10.


Multiple choice grid
  * You can create a grid where responders can select one or more answers per row.
  * This type of question is often used to rate a category of options.
  * You can add options for rows and columns, and set up optional rules like limit one choice per column. [Learn how to set rules for your form](https://support.google.com/docs/answer/3378864#rulesmultiplegrid).


Checkbox grid
  * You can create a grid where responders can select one or more answers per row.
  * This type of question is often used to rate a category of options.
  * You can add options for rows and columns, and set up optional rules like limit one choice per column. [Learn how to set rules for your form](https://support.google.com/docs/answer/3378864#rulescheckboxgrid).


Date
Responders can fill out a date in mm/dd/yyyy format.
To include the year or time, at the bottom right of the question, click More ![](https://storage.googleapis.com/support-kms-prod/og5HHfAGvY6IERh0tFkgoGRBhHTxgavp1qzG).
Time
Responders can fill out the:
  * Time in hh:mm AM/PM format
  * Duration in Hrs Min Sec format


To switch between time or duration, at the bottom right of the question, click More ![](https://storage.googleapis.com/support-kms-prod/og5HHfAGvY6IERh0tFkgoGRBhHTxgavp1qzG).
