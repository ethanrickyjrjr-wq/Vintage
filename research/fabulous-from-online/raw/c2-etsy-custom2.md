# How to Request a Personalised or Custom Item 
Make the items you find on Etsy even more uniquely “you” by requesting personalisation. If a seller offers personalised items, you can add your personalisation from the listing page. You can also request custom, made-to-order items.
## **How to personalise an item**
If an item can be personalised, you’ll see **Add personalisation** on the listing page.
To personalise an item:
  1. On [Etsy.com ](https://www.etsy.com)or the Etsy app, open a listing that you want to buy.
  2. Choose the options you’d like for the order. This will differ depending on what options are available for the item.
  3. Select **Add personalisation**. You’ll see any information the seller needs to personalise your item listed in the dropdown. Fill out the requested information in the text box.
  4. Click **Buy it now** or **Add to basket** and proceed to checkout.


If you don't see **Add personalisation** on the listing page, the seller might still be able to accommodate you. Try [contacting them via Messages](https://help.etsy.com/hc/articles/115013328428?segment=shopping).
If the personalised item you’re ordering uses a photograph or image, you can send it to the seller via Messages. Be sure to check the listing details to see if the seller has any special instructions for the image you send.
## **How to find items you can personalise in Etsy search**
To find items you can personalise on [Etsy.com](http://etsy.com) and the Etsy app: 
  1. Search for the item you’re looking for in the search bar. 
  2. Select **Filters**. 
  3. Select the **Special offers** dropdown. 
  4. Check the **Personalisable** box. 


The items displayed will have the option to be personalised.
## **How to request a custom item**
To request a custom item, you’ll need an account on Etsy. [Learn how to create an Etsy account](https://help.etsy.com/hc/articles/115015568007?segment=shopping).
If a seller offers custom items, you’ll see a **Request Custom Order** button on their shop homepage. If you don't see the **Request Custom Order** button, the seller might still be able to accommodate you. Try [contacting them via Messages](https://help.etsy.com/hc/articles/115013328428?segment=shopping).
Here are some suggestions on how to best convey what you're looking for:
  * If you’d like to have something made based on an existing item on Etsy, send your request from the **Message seller** button on that item listing page.
  * Add an image to help illustrate what you’re looking for. If you've already been messaging with the seller, select the image icon in your conversation to upload an image. Or, send a new message by selecting **Contact** during checkout. 
  * Ask how much the custom piece will cost depending on time, materials, or other details.
  * Discuss the length of time it will take to make the item.
  * Add a “needed by” date if you require the item by a particular time.


Discuss the specifics of your request with your seller to make sure you both know what will be created.
### **After you send a request**
Once you send a custom request, you’ll see a **Custom Requests** folder in your [Messages](https://help.etsy.com/hc/articles/115015654988?segment=shopping). Check the folder for updates from the seller on the item's progress.
If the seller can create the item, they may publish a private custom listing for you. 
When the seller finishes your item, you’ll be notified via email and Messages that your order is ready to purchase. You can add the listing to your basket directly from the request page or from the private listing page. This way, the seller has a record of the transaction, and you have a safe and secure way to pay for the item.
This listing won't be publicly viewable in Etsy Search or the shop before purchase. However, it will appear with the seller's other public sold items after you buy it.
