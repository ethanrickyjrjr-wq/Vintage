Thank you for posting your question in the Q&A Forum. 
In Classic Outlook for Windows, extremely long URLs (for example, 11,000+ characters) are not supported as clickable hyperlinks. If a URL is excessively long, Outlook may prevent the message from being sent or the hyperlink may not function correctly.
You may still include the full 11,000+ characters as plain text within the email body. In this case, it will display correctly, but it will not function as an active clickable link.
If a clickable link is required, we recommend shortening the URL or sharing the content using an alternative format, such as an attachment or a file containing the complete link. This is the expected behavior in Outlook Desktop.
For information on customizing or changing the display text for a hyperlink in Outlook, please refer to the official Microsoft support article: [Customize the text for a hyperlink in Outlook - Microsoft Support](https://support.microsoft.com/en-us/office/customize-the-text-for-a-hyperlink-in-outlook-63d4fdcc-bce2-41ea-9649-d8aaa900fe2f)

In classic Outlook for Windows, the key URL-length behavior documented is:
    1. For regular hyperlinks in message bodies, Outlook historically had an internal limit of 2,084 characters per URL. When Safe Links wrapped very long URLs and the 2,084th character was an escaped character, Outlook could not send the message and showed the error “Cannot send this item.”
    2. This issue has been fixed in newer Outlook builds. The URL limit was increased from 2,084 to 8,192 characters in Outlook Desktop build 16116.10000 and later (for supported channels) together with a required Windows update.
So, for both plain and masked hyperlinks (where display text is different from the underlying URL), the effective limit for the URL itself in updated Outlook Desktop is 8,192 characters. The display text (mask) is not called out as having a separate, specific character limit in the provided context.
