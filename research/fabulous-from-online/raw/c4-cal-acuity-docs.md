#  Request documents from clients at booking 
Collect documents, images, and other files from clients with their appointments.
## Article Summary
Last updated July 10, 2026
You can use custom intake forms to ask clients to upload specific documents before their appointment. These file uploads will be attached to their appointment details.
## Add file upload questions to your forms
Add a file upload question so clients can upload images, documents, or other files up to 5 MB.
  1. Open the [Intake Form Questions page](https://secure.acuityscheduling.com/forms.php).
  2. When [creating a new form or editing an existing form](https://help.acuityscheduling.com/hc/en-us/articles/16676931038093), add a **File Upload** question.
  3. Add text to the **Question** field. You can use up to 255 characters, including spaces.
  4. To make a question required, check **Required**.
  5. To have clients upload multiple files, add multiple file upload questions.
  6. Drag and drop the questions into the order you want.
  7. In the **Show this form when scheduling** section, click which appointment types should include this form.
  8. Click **Save form**.


## Access an uploaded file
You need to be logged into your account to access uploaded files. When clicking on a file link in a third-party calendar or .ics attachment, you'll be taken directly to the file in your Acuity account.
To access an uploaded file in your Acuity account:
  1. Open the [Calendar page](https://secure.acuityscheduling.com/appointments.php).
  2. Click the appointment that has the file you want to access.
  3. Scroll down to the file and click the file link.


## Delete an uploaded file
To delete a file that a client uploaded through an intake form:
  1. Open the [Calendar page](https://secure.acuityscheduling.com/appointments.php).
  2. Click the appointment that has the file you want to delete.
  3. Click **Edit**.
  4. Scroll down to the file and click **Remove file** , then click **OK**.
