# How to Set Up Sales and Discounts for Your Shop 
Etsy provides sellers with four ways to discount items in your shop: sales, promo codes, discounted bundles of items, and targeted offers.

## How to create a promo code
Buyers can receive discounts during checkout using promo codes you’ve set up for your shop. You can share codes with buyers in [Messages](https://help.etsy.com/hc/articles/115015654988?segment=selling), in your [shop announcement](https://help.etsy.com/hc/articles/360000343708?segment=selling), on social media, or anywhere else where you interact with your customers. 
To create a promo code:
  1. On [Etsy.com](https://www.etsy.com/), go to your **Shop Manager**.
  2. In the **Marketing** tab, select [**Sales and Discounts**](https://www.etsy.com/your/shops/me/sales-coupons).
  3. Choose **Create a promo code**.
  4. Select the options you’d like for your discount. 
  5. Choose which individual listings will be eligible for this promo code, or select **Add all active listings**.
  6. Review the details for your promo code, and select **Confirm and create code**.


### **What are the available discount types?**
When creating a promo code, you can choose from the following discount types:
  * **Percentage off** : Offer any percentage off between 5% and 75% off the list price of items in your shop. The percentage off must be a whole number. 
  * **Fixed amount off** : Offer a fixed amount off the list price of items in your shop.
  * **Free standard shipping** : The shopper won’t pay a shipping fee. You can choose to only offer free shipping on domestic orders or selected regions. [Learn how to offer free shipping](https://www.etsy.com/seller-handbook/article/smart-strategies-for-running-a-free/176426041624).


If you choose to only offer a percentage-off discount on certain listings, you will need to manually add new listings to your existing promo codes. You can[ edit the sale or discount](https://www.etsy.com/your/shops/me/sales-coupons) later to include them. 
### **Can I set a limit on how many times promo codes can be used?**
You can set a maximum number of times a promo code can be used across all buyers, or select **No limit** to allow unlimited use. Once the code is created, this limit can’t be changed, but you can deactivate the code at any time. If you set a redemption limit, it’s a good idea to communicate it clearly to buyers (for example, “While supplies last” or “Only 50 available”) as well as any expiration date you set.
You also can limit a code to one use per buyer. This helps prevent overuse while still allowing the code to be shared.
## How to run a sale
When you run a sale on Etsy, you’re offering a discount on some or all of the items in your shop for a set audience for a certain period of time. 
To set up a sale ordiscount:
  1. On [Etsy.com](https://www.etsy.com/), go to your **Shop Manager**.
  2. In the **Marketing** tab, select [**Sales and Discounts**](https://www.etsy.com/your/shops/me/sales-coupons).
  3. Select **Run a sale**.
  4. Choose between a **Percentage off** or **Free standard shipping** sale. 
  5. Customize the details of your sale, setting parameters like the discount amount, which countries the offer is valid in, and more.
  6. Select **Review and confirm**.


Etsy periodically has site-side sales events that you can choose to participate in. [Learn more about Etsy-wide sales.](https://help.etsy.com/hc/articles/360039531534?segment=selling)
### **Can I run listing-specific sales as well as shop-wide sales?**
If you don’t set a minimum order to qualify, you will be able to select specific listings to include in the sale. You can[ edit the sale](https://www.etsy.com/your/shops/me/sales-coupons) later to include new listings if needed.
If you do set a minimum order to qualify, your sale will be shop-wide and you won’t be able to exclude items from it.
### **Can I run multiple sales at the same time?**
You can run multiple sales at the same time, but if more than one sale applies to a listing, only the highest discount will be used. Sales will conflict if they overlap in time, target the same region, and apply to the same listings. Etsy automatically checks for these conflicts when you create a new sale. 
Types of conflicting sales: 
  * **Shop-wide + shop-wide:** If you’re already running a sale across your entire shop, creating another shop-wide sale at the same time isn’t recommended, since only the highest discount will apply.
  * **Listing-level + listing-level:** If multiple sales include the same items, only the best discount will be applied to those listings.
  * **Shop-wide + listing-level:** A shop-wide sale includes all listings, so it will conflict with any listing-level sale running at the same time. However, if the listing-level sale offers a higher discount, it will take priority for those listings.


When you run a sale on Etsy, you are responsible for following applicable consumer protection laws and Etsy’s policies. [Learn more in our best practices guide](https://www.etsy.com/seller-handbook/article/1450964704111).
## How to set up a discount with an order minimum
You can set up a discount with an order minimum to help boost order value.
To set an order minimum: 
  1. Go to your [**Shop Manager**](https://www.etsy.com/your/shops/me/dashboard). 
  2. Choose **Marketing** and select [**Sales and Discounts**](https://www.etsy.com/your/shops/me/sales-discounts?ref=seller-platform-mcnav). 
  3. Under **Set an order minimum** , select **Set up**. 
  4. Choose your discount amount, your order minimum, start and end dates, and where the offer is valid.
  5. Select **Create discount**.


## How to create discounted bundles of items
You can encourage buyers to purchase items that pair well together from your shop by offering discounted bundles of items. 
To create a discounted bundle of items: 
  1. Go to your [**Shop Manager**](https://www.etsy.com/your/shops/me/dashboard). 
  2. Choose **Marketing** and select [**Sales and Discounts**](https://www.etsy.com/your/shops/me/sales-discounts?ref=seller-platform-mcnav). 
  3. Under **Bundle items together** , select **Set up**. 
  4. Add up to 3 listings to offer together. You can search through your listings and filter through your shop sections. 
  5. Select a discount amount from the dropdown menu. 
  6. Select **Create offer**. 


Buyers must purchase all of the items in the bundle to be eligible for the discount you set. Buyers see what items are part of discounted bundles in the item’s listing page. They’re also shown a badge displaying bundled items based on the items from your shop in their cart.
More information about discounted bundles 
  * Listings can only be part of one discounted bundle at a time.
  * Bundle discounts will not stack with other sales and promotions you’re offering. Buyers will need to choose which promotional offer they want to redeem.


## How to send targeted offers
You can create promo codes that are automatically emailed to shoppers who have shown interest in your items. The shopper can then enter the promo code at checkout. Set targeted offers under **Send offers to interested buyers** on your [**Sales and discounts**](https://www.etsy.com/your/shops/me/sales-coupons) page.
### **What kind of offers can I send?**
There are 4 types of targeted email offers for shoppers opted-in to receiving marketing email messages:
Abandoned cart 
  * If a buyer has an item for your shop in their cart for more than 2 hours, they’ll get an email offering them a discount for that item.
  * A buyer can receive this type of targeted offer email once every 2 days. We’ll include up to 12 eligible abandoned cart offers per offer email.
  * Offer expires 60 days from the coupon’s creation date.


Favorited item 
  * If a buyer has favorited an item in your shop, they’ll get an email offering them a discount for that item. 
  * A buyer can receive this type of targeted offer email once every 2 days. We’ll include up to 12 different discounts per offer email.
  * Offer expires 60 days from the coupon’s creation date.


Interested shopper 
  * If a buyer shows interest in your listing, they’ll get an email offering a discount for that item.
  * Etsy determines interested shoppers using a number of factors, including how often and how recently they’ve viewed your listings.
  * A buyer can receive this type of targeted offer email once every 30 days.
  * Offer expires 7 days from the coupon’s creation date and can only be used once.


Thank you 
  * After a buyer has purchased from you, they are sent a targeted offer email to encourage them to buy from you again.
  * This offer email is sent to the buyer after the order is completed.
  * Offer expires 1 year after it’s sent.


### **How long will my targeted offer last?**
A campaign will continue to run until: 
  * You decide to stop it by choosing **Details** under the discount on your[ Sales and discounts](https://www.etsy.com/your/shops/me/sales-coupons) page.
  * The offer’s expiration date passes. 


If you end a targeted offer campaign, no new offer codes will be sent to buyers. However, codes that were already issued may still be redeemed until they expire.
Etsy may adjust the mechanics of targeted offers from time to time, including eligibility criteria, frequency, and discount types.
### **How are targeted offers applied?**
Buyers can redeem one targeted offer at a time. If a listing is on sale and a shopper also receives a targeted offer for it, only the highest discount will apply at checkout.
### **Why didn’t a shopper receive a targeted offer?**
[Learn more about why buyers may have not received a targeted offer.](https://help.etsy.com/hc/articles/360036985673?segment=selling)
## How free shipping works with other discounts
If you offer more than one promotion, shoppers can apply both a list price discount and free shipping to an order.
The order must be eligible for both promotions for a shopper to apply both discounts.
If you don’t have an active free shipping promotion, then shoppers won’t see the option to apply more than one discount to an item in your shop.
[Learn more about strategies for free shipping promotions.](https://www.etsy.com/seller-handbook/article/smart-strategies-for-running-a-free/176426041624)
## How to see your current and scheduled sales and discounts
To check to see that your sales and discounts have been set up properly:
  1. Go to [**Sales and discounts**](https://www.etsy.com/your/shops/me/sales-coupons). 
  2. Navigate to **Offer details and stats**. 


Here, you’ll be able to see which offers you currently have available, the duration of your promotion, and your other stats. 
## How to review performance of sales and discounts
Track the performance of your offers by going to the **Individual sales and offers** section of [**Sales and discounts**](https://www.etsy.com/your/shops/me/sales-coupons). You can select a time frame, then view information about your offers such as:
  * Activation status
  * Discount
  * Duration
  * Offers granted
  * Purchases
  * Conversion rate
  * Revenue
