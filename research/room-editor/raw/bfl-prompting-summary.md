# FLUX Prompting Guide
Copy pageCopy page
Prompt FLUX 3 Image with text, reference images, and optional bounding boxes.
Copy pageCopy page
Describe the image you want: the subject, setting, style, lighting, and composition. Refer to input images by position (“image 1”, “image 2”), and add bounding boxes when you need to specify where elements go. For example, this image came from the one-sentence prompt below it:
![Ultra-wide shot of a vintage car with its headlights on, driving a wet coastal road between fog-covered cliffs and a turquoise sea at dawn](https://cdn.sanity.io/images/2gpum2i6/production/29a4ca87e605029fa9b98a14fa8c07f53a0c2ef2-1800x773.webp)
