##

Camera & Lens Cheat Sheet  
| Term  | Effect  |  
| --- | --- |  
| **f/1.4 – f/2.8**  | Blurry background (shallow depth of field)  |  
| **f/8 – f/16**  | Everything sharp (deep depth of field)  |  
| **24mm**  | Wide angle: shows more of the scene  |  
| **35mm**  | Natural, documentary-style perspective  |  
| **50mm**  | Eye-level, neutral perspective  |  
| **85mm**  | Portrait-ideal, slight background compression  |  
| **135mm+**  | Telephoto: strong background compression  |  
| **ISO 100**  | Clean image, low noise  |  
| **ISO 1600–3200**  | Brighter but grainy: useful for film-style looks  |  
| **Macro lens**  | Extreme close-up detail  |  
| **Anamorphic lens**  | Widescreen cinematic look with oval bokeh  |  
## 
[​](https://docs.bfl.ai/guides/prompting_unified_reference#lighting-keywords)
Lighting Keywords
Describe the light source, its direction, and whether it is soft or harsh.  
| Term  | Effect  |  
| --- | --- |  
| **Golden hour**  | Warm, soft, flattering: just after sunrise or before sunset  |  
| **Blue hour**  | Cool, moody: just before sunrise or after sunset  |  
| **Overcast**  | Flat, even, shadow-free: suits product shots  |  
| **Rembrandt lighting**  | Dramatic triangle of light on the face  |  
| **Split lighting**  | High contrast, half-face illuminated  |  
| **Chiaroscuro**  | Strong light/shadow drama  |  
| **Backlit / rim light**  | Subject glowing at the edges  |  
| **Soft box / key light**  | Studio, controlled, even  |  
| **Practical lighting**  | Light sources visible in the scene (lamps, neon, fire)  |  
| **Diffused light**  | Soft, wrap-around, minimal shadows  |  
| **Harsh direct light**  | Strong shadows, high contrast  |

## 
[​](https://docs.bfl.ai/guides/prompting_unified_reference#composition-techniques)
Composition Techniques  
| Technique  | When to Use  | Example Phrase  |  
| --- | --- | --- |  
| **Rule of thirds**  | Natural, balanced framing  | “composed using rule of thirds”  |  
| **Leading lines**  | Guide the eye through the image  | “diagonal lines leading to main entrance”  |  
| **Foreground/background layers**  | Add depth and dimension  | “strong foreground boulder, background mountains”  |  
| **Low angle (worm’s eye)**  | Make subjects look large and dominant  | “low angle worm’s eye view, dramatic diagonal lines”  |  
| **High angle (bird’s eye)**  | Show patterns and spatial relationships  | “bird’s eye view, geometric patterns of city blocks”  |  
| **Dutch angle**  | Tension and psychological unease  | “dutch angle, psychological tension”  |  
| **Symmetrical**  | Formal, balanced, architectural  | “perfectly symmetrical composition”  |  
| **Negative space**  | Minimal, focused, product  | “minimalist composition with generous negative space”  |  
## 
[​](https://docs.bfl.ai/guides/prompting_unified_reference#model-specific-quick-reference)
Model-Specific Quick Reference
FLUX 3 Image
  * Start with a short description. FLUX 3 Image expands it before generating, so add detail only for what you want to control: positions, appearance, light, or text.
  * Refer to references by position: “image 1” is the first entry in `images`. Send up to 10.
  * For layout control, follow the caption with an element table: `{"id", "bbox", "desc"}` rows, boxes as `[top, left, bottom, right]` on a 0 to 1000 grid, each id cited in the caption as `<id>`. Set `aspect_ratio` to the shape you drew the boxes for.

In this example, `[150, 150, 850, 850]` puts the runner in the middle 70% of the frame. Hover over the caption to see each box, or move the pointer over the image to read its coordinates:
  * Write edits as a record: `Modify <ref_image_0> by replacing … with … Keep the rest of the image exactly unchanged, preserving …`
  * Use a hex code to specify a target color: `change the color of only one bird in the middle to #e01075`
  * Quote the exact words for text in the image and describe the type: weight, case, color, alignment. Multi-line posters and Japanese text render in the launch examples.
  * There are no `negative_prompt`, `seed`, `prompt_upsampling`, or `guidance` fields. Unknown fields return `422`.

See: [FLUX 3 Text to Image →](https://docs.bfl.ai/flux_3/flux3_image_generate) · [Layout prompts →](https://docs.bfl.ai/guides/prompting_layout) · [FLUX 3 Image Editing →](https://docs.bfl.ai/flux_3/flux3_image_layout) · [Precise editing →](https://docs.bfl.ai/flux_3/flux3_image_bounding_boxes#edit-an-image)
FLUX.2 (all variants)
**Other languages** FLUX.2 can be prompted in multiple languages, so you don’t need to write in English. English prompts tend to produce the most precise results, since most of the training data is in English.**Reference images per API request**  
| Model  | References  | How you send them  |  
| --- | --- | --- |  
|  **FLUX.2 [max]** , **[pro]** , **[flex]**  | Up to **8** (up to **10** in the BFL Playground)  |  `input_image` … `input_image_8`  |  
|  **FLUX.2 [klein] 9B** , **[klein] 4B**  | Up to **4**  |  `input_image` … `input_image_4`  |  
| **FLUX.2 [dev]**  | Recommended max **6**  | Set by your inference code (open weights)  |  
FLUX.2 [pro] has a 9 MP total limit for input plus output. At 1 MP output you can use up to 8 reference images, at 2 MP output up to 7, and so on.See: [Multi-Language →](https://docs.bfl.ai/guides/usecases_t2i_multi_language) · [Which FLUX.2 model to choose →](https://docs.bfl.ai/flux_2/flux2_overview#which-model-to-choose)
FLUX.2 [pro] & [max]
  * No negative prompts supported
  * Excellent typography: use quotation marks for exact text
  * Hex color codes in text-to-image prompts for brand colors, text, and gradients: _“The logo text ‘ACME’ in color #FF5733”_
  * JSON structured prompts supported for production workflows
  * Reference specific camera models for authentic photorealistic looks

**Text tips**
  * **Front-load text descriptions** for better accuracy
  * **Keep text short** : long strings are harder to render accurately

See: [JSON Prompting →](https://docs.bfl.ai/guides/usecases_t2i_json_prompting) · [Typography & Design →](https://docs.bfl.ai/guides/usecases_t2i_typography_design) · [HEX Color Prompting →](https://docs.bfl.ai/guides/usecases_t2i_hex_color_prompting)
FLUX.2 [klein]
  * What you write is exactly what the model receives
  * Write in prose, not keyword lists: describe scenes like a novelist
  * Describe the light source, direction, and softness
  * Supports image editing with single and multi-reference inputs: up to 4 reference images (`input_image` … `input_image_4`)
  * Add `Style: [style]. Mood: [mood].` at the end for consistent aesthetics

See: [Single-Reference Editing →](https://docs.bfl.ai/guides/prompting_editing_single_reference) · [Multi-Reference Editing →](https://docs.bfl.ai/guides/prompting_editing_multi_reference)
FLUX.1 Kontext
  * Specify what should **change** : the input image provides all other visual context
  * Use quotation marks for text editing: `Replace 'joy' with 'BFL'`
  * Be explicit about preservation: _“while maintaining the same facial features and hairstyle”_
  * Prefer specific verbs: “change the clothes” over “transform the person”
  * For multiple changes, add as many explicit details as possible
