# FLUX 3 Image Klein
[](https://github.com/black-forest-labs/flux-3-image-klein#flux-3-image-klein)
[Model page](https://bfl.ai/models/flux-3-image-klein) • [Weights](https://huggingface.co/black-forest-labs/flux-3-image-klein) • [Demo](https://github.com/black-forest-labs/flux-3-image-klein#demo)
This repository contains the reference inference code for [FLUX 3 Image Klein](https://bfl.ai/models/flux-3-image-klein), the 5.6B open weights image model from [Black Forest Labs](https://bfl.ai): text-to-image, editing with up to 10 reference images, and layout control with bounding boxes, through one model. It ships with a [prompt upsampler](https://github.com/black-forest-labs/flux-3-image-klein#prompt-upsampling); do not use the model without it.
[![FLUX 3 Image Klein text-to-image](https://github.com/black-forest-labs/flux-3-image-klein/raw/main/assets/hero.jpg)](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/assets/hero.jpg)
## Performance
[](https://github.com/black-forest-labs/flux-3-image-klein#performance)
Leads in quality and speed among open weights models: the Pareto frontier of Elo rating against latency, for text-to-image and for image editing.
[![Elo rating vs median latency, text-to-image and image editing](https://github.com/black-forest-labs/flux-3-image-klein/raw/main/assets/elo_latency.jpg)](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/assets/elo_latency.jpg)
Elo from our internal evaluations; median API latency for a 1 MP image.

## Which model should I use?
[](https://github.com/black-forest-labs/flux-3-image-klein#which-model-should-i-use)  
| Need  | Recommended  |  
| --- | --- |  
| Generation and editing, self-hosting  | FLUX 3 Image Klein (distilled): the same model in 16 steps without CFG, about 6x faster  |  
| Fine-tuning, LoRA training, research  | FLUX 3 Image Klein Base  |  
| An 8 GB GPU (RTX 3070 class)  | the int8 files in [ComfyUI](https://github.com/black-forest-labs/flux-3-image-klein#run-it-elsewhere)  |  
Important
Do not use either model without the [prompt upsampler](https://github.com/black-forest-labs/flux-3-image-klein#prompt-upsampling). The model is trained on the captions it writes; a prompt sent as typed gives noticeably weaker results. It is on by default in the CLI, the demo and the Python API.

## Local installation
[](https://github.com/black-forest-labs/flux-3-image-klein#local-installation)
To run FLUX 3 Image Klein in BF16 and FP8:

```
python3.12 -m venv .venv && . .venv/bin/activate
pip install -e . --extra-index-url https://download.pytorch.org/whl/cu130
```

To run FLUX 3 Image Klein in BF16, FP8 and NVFP4 (NVFP4 needs a Blackwell GPU):

```
python3.12 -m venv .venv && . .venv/bin/activate
pip install -e '.[nvfp4]' --extra-index-url https://download.pytorch.org/whl/cu130 --extra-index-url https://flashinfer.ai/whl/cu130
```

The installation was tested on B200; see [Memory](https://github.com/black-forest-labs/flux-3-image-klein#memory) for other GPUs.
### Weights
[](https://github.com/black-forest-labs/flux-3-image-klein#weights)
The fast model with its prompt upsampler, 52 GB:

```
hf download black-forest-labs/flux-3-image-klein --local-dir weights/flux-3-image-klein --exclude 'variants/*'
hf download black-forest-labs/flux-3-image-klein-pup --local-dir weights/pup
hf download Falconsai/nsfw_image_detection --local-dir weights/nsfw-classifier
```

Everything, 107 GB:

```
hf download black-forest-labs/flux-3-image-klein-base --local-dir weights/flux-3-image-klein-base
hf download black-forest-labs/flux-3-image-klein --local-dir weights/flux-3-image-klein
hf download black-forest-labs/flux-3-image-klein-pup --local-dir weights/pup
hf download Falconsai/nsfw_image_detection --local-dir weights/nsfw-classifier
```

`WEIGHTS_DIR` points at another root (default `./weights`). The quantized DiTs live under `variants/fp8r` and `variants/nvfp4` in each repository; the text encoder and autoencoder ship with both. `weights/pup` is the [prompt upsampler](https://github.com/black-forest-labs/flux-3-image-klein#prompt-upsampling), which the model needs.
## Run the CLI
[](https://github.com/black-forest-labs/flux-3-image-klein#run-the-cli)
Important
The commands below send the prompt through the [upsampler](https://github.com/black-forest-labs/flux-3-image-klein#prompt-upsampling) before the model. Do not pass `--no-pup` unless the prompt already is an upsampler caption ([Smaller GPUs](https://github.com/black-forest-labs/flux-3-image-klein#smaller-gpus)).
### Text to image
[](https://github.com/black-forest-labs/flux-3-image-klein#text-to-image)

```
python scripts/cli.py "A man walking with his dog, afternoon sun" --model distilled --out out.png --seed 7
```

Each generated image comes with a `.json` containing the prompt, size, number of steps, guidance value and seed; [examples/README.md](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/examples/README.md) has the command behind every image in this README.
### Edit an image
[](https://github.com/black-forest-labs/flux-3-image-klein#edit-an-image)

```
python scripts/cli.py "put a red bandana around the dog's neck" --image examples/inputs/3.png --out out.png --seed 22
```

Up to 10 references; the first one sets the output size:

```
python scripts/cli.py "print the dog from the second image onto the mug" \
  --image examples/inputs/2.png --image examples/inputs/3.png --out out.png --seed 23
```

### Place elements with bounding boxes
[](https://github.com/black-forest-labs/flux-3-image-klein#place-elements-with-bounding-boxes)

```
python scripts/cli.py "hot-air balloons over a green valley at sunrise" \
  --boxes examples/inputs/balloons_boxes.json --out out.png --seed 1
```

Format in [Bounding boxes](https://github.com/black-forest-labs/flux-3-image-klein#bounding-boxes).
### Smaller GPUs
[](https://github.com/black-forest-labs/flux-3-image-klein#smaller-gpus)
`--fp8` (Ada, Hopper, Blackwell) or `--nvfp4` (Blackwell) load the quantized DiTs.
An external vision-language model can also write the caption in place of the upsampler: give it the [system prompts](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/src/flux3/pup_prompts_external_vlm.json) and pass its answer with `--no-pup`.
When the upsampler and the model do not fit on the GPU together, run the upsampler on its own first and pass its caption with `--no-pup`:

```
python -m flux3.pup --prompt "A man walking with his dog, afternoon sun" --out prompt.txt
python scripts/cli.py "$(cat prompt.txt)" --model distilled --fp8 --no-pup --out out.png
```

Numbers in [Memory](https://github.com/black-forest-labs/flux-3-image-klein#memory).
### From Python
[](https://github.com/black-forest-labs/flux-3-image-klein#from-python)

```
from PIL import Image

from flux3.generate import Models, generate
from flux3.pipeline import WEIGHTS, dit_path

models = Models({"distilled": str(dit_path("distilled"))}, pup=str(WEIGHTS / "pup"), pup_memory=0.35)

image, record = generate(models, "distilled", "a red bicycle leaning on a white wall", images=[], seed=1)
image.save("bicycle.png")

image, record = generate(models, "distilled", "put a red bandana around the dog's neck",
                         images=[Image.open("examples/inputs/3.png")], seed=22)
image.save("bandana.png")
```

`Models` loads once; `generate` also takes `boxes`, `width`, `height`, `steps`, `guidance`, `pup`, `safety`.

## Prompt upsampling
[](https://github.com/black-forest-labs/flux-3-image-klein#prompt-upsampling)
The upsampler ([black-forest-labs/flux-3-image-klein-pup](https://huggingface.co/black-forest-labs/flux-3-image-klein-pup), a 9B vision-language model fine-tuned from Qwen3.5-9B) expands a short request into the detailed prompt the model works best with, before it reaches the text encoder. It is on by default in the CLI, the demo and `generate`. Do not use the model without it, for text-to-image, editing and layout alike: `--no-pup` sends the prompt as typed, and the results are noticeably weaker.  
| input prompt  | what the model saw  |  
| --- | --- |  
| `double exposure portrait: a young East Asian man facing the camera, a larger translucent profile of him facing left layered over him, muted blues, film grain, silver hoop earring`  | "Digital double-exposure portrait in a muted blue monochrome palette, framed as a head-and-shoulders composition with visible 35mm film grain. Centered in the foreground, a young East Asian man in his twenties faces the camera directly ... a polished silver hoop earring hangs from his left ear. His face remains sharply defined beneath a larger translucent profile of the same man layered across it, facing left ..." (214 words, [examples/upsampling/double_exposure_s1.json](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/examples/upsampling/double_exposure_s1.json))  |  
[![](https://github.com/black-forest-labs/flux-3-image-klein/raw/main/examples/upsampling/double_exposure_s1.png)](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/examples/upsampling/double_exposure_s1.png) [![](https://github.com/black-forest-labs/flux-3-image-klein/raw/main/examples/upsampling/double_exposure_s2.png)](https://github.com/black-forest-labs/flux-3-image-klein/blob/main/examples/upsampling/double_exposure_s2.png)

```
python scripts/cli.py "double exposure portrait: a young East Asian man facing the camera, a larger translucent profile of him facing left layered over him, muted blues, film grain, silver hoop earring" \
  --model distilled --width 832 --height 1248 --seed 1 --out out.png
```

Upsample without generating:

```
python -m flux3.pup --prompt "double exposure portrait: a young East Asian man facing the camera, a larger translucent profile of him facing left layered over him, muted blues, film grain, silver hoop earring" --out prompt.txt
```

## Bounding boxes
[](https://github.com/black-forest-labs/flux-3-image-klein#bounding-boxes)
`boxes.json` is a list of boxes, `[y_min, x_min, y_max, x_max]` in 0 to 1, top-left origin:

```
[{"id": "obj_1", "desc": "a red hot-air balloon", "bbox": [0.08, 0.10, 0.45, 0.42]},
 {"id": "obj_2", "desc": "a lighthouse on a cliff", "bbox": [0.30, 0.60, 0.95, 0.90]}]
```

For edits, a box is `{"id", "desc", "from": "ref_image_0" | "target", "src_bbox", "tgt_bbox"}`: where it is in a reference, where it goes in the output, or both.

## Memory
[](https://github.com/black-forest-labs/flux-3-image-klein#memory)
Peak GPU memory (nvidia-smi) on a B200 at 1024x1024, text-to-image and an edit with one reference:  
|   | bf16  | `--fp8`  | `--nvfp4`  |  
| --- | --- | --- | --- |  
| `cli.py --model distilled --no-pup`  | 31 GB  | 26 GB  | 25 GB  |  
| `cli.py --model base --no-pup`  | 31 GB  | 29 GB  | 26 GB  |  
The upsampler reserves `--pup-memory` of the GPU (default 0.35). `--fp8` needs Ada, Hopper or Blackwell; `--nvfp4` needs Blackwell and the `[nvfp4]` install, not with `--offload`.
This code has no int8 path. On GPUs without FP8 (RTX 30 series and older) use the int8 files from [black-forest-labs/flux-3-image-klein-comfy](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy) in ComfyUI.
## Safety
[](https://github.com/black-forest-labs/flux-3-image-klein#safety)
Off by default; `--safety` (CLI) or **Advanced, Safety checks** (demo). Prompts, reference images and outputs are checked for copyrighted characters, brands and public figures (VLM) and for NSFW content (classifier); anything flagged is refused. Saved images carry EXIF tags (`Software: AI generated`, `Make: Black Forest Labs`).
