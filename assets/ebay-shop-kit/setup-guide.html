Returns and international orders

Buyer-paid change-of-mind postage does not apply to damage, faults, wrong items or a description mismatch. Those returns require seller-paid return shipping under the applicable eBay protection. Use the return request's address and instructions. Return shipping.

Recommended choices: no restocking fee, no automatic refund-without-return rule at launch, and human review of exceptions. Check returns daily and follow the displayed response deadline. After a return arrives, review and refund within two business days or use eBay's resolution process. Never condition a refund on a favorable review. Handling returns.

For local pickup, explain that change-of-mind returns require buyer-arranged return transport. Arrange seller-responsible returns through eBay where applicable. Furniture is not automatically exempt from the approved return promise. At handover, verify payment and scan the buyer's QR code or enter the six-digit pickup code in the order. Local pickup.

Inspect eBay International Shipping enrollment before changing international settings. For eligible sales, the seller sends the properly packed item to eBay's domestic hub and eBay handles the international leg and program returns. This differs from self-managed international shipping.
